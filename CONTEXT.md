# Domain terms

- **Freeze**: temporarily replace a track's live instrument and track effects with audio rendered from that track, while retaining its MIDI and plugin source for later editing.
- **Frozen render**: the managed audio produced by Freeze. It follows the normal track playback path, so track fader, pan, routing, and Master processing remain live.
- **Unfreeze**: remove the active frozen render and resume the retained source instrument and effects.
- **Freeze tail**: the short post-content interval rendered so plugin release and effect decay are preserved.
