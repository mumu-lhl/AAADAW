# Initial Timebase Defaults

**Status: accepted.** New projects start at 48 kHz, 960 PPQ, 120 BPM, and 4/4. Tempo points use step interpolation by default and may select linear-BPM interpolation to the next point. Sample anchors are cached per point; ramp conversion integrates the changing BPM and inverse conversion uses the corresponding logarithmic inverse. Conversions round to the nearest integer sample or tick. Time signatures change only at bar lines, and tempo, curve, and meter changes are atomic `DawAction`s with undo/redo. Additional curve types and higher-precision long-range conversion remain follow-up work.
