# Initial Timebase Defaults

**Status: accepted.** New projects start at 48 kHz, 960 PPQ, 120 BPM, and 4/4. Tempo points use step interpolation by default and may select linear-BPM, logarithmic-BPM, or smooth cubic Bézier interpolation to the next point. The Bézier mode fixes control values at the endpoint BPMs, giving horizontal endpoint tangents without extra per-point parameters. Sample anchors are cached per point; ramp conversion integrates the changing BPM, with analytic inverses for linear/logarithmic ramps and bounded numerical integration/inversion for Bézier ramps. Conversions round to the nearest integer sample or tick. Time signatures change only at bar lines, and tempo, curve, and meter changes are atomic `DawAction`s with undo/redo. Schema v12 preserves existing step/linear values while admitting the new curve identifiers.
