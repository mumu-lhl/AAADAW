# Audio asset imports are immutable snapshots

The default external-file import stores an immutable snapshot in the project and leaves the original file untouched; the original path and SHA-256 fingerprint support stale-source checks, but edits never silently change existing playback. An explicit external-link mode instead follows the current file and may break when it moves. Packing a link snapshots its current contents while preserving the media reference. Refreshing an embedded asset creates a new reference and updates placements through undoable project actions, avoiding silent changes to every item sharing the old asset.
