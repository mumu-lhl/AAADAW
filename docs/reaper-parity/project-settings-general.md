# Project Settings General（阶段实现）

固定参照 Linux REAPER 7.82 / Default 7 / factory。General 页原厂默认 BPM 120、Time signature 4/4、Start measure 1、BPM basis 1/4、Base ruler label spacing 开启，与[原厂设置窗口的数值记录](project-settings-general-reference.json)互证。AAADAW 将 BPM、拍号和 BPM basis 放在同一行，与原厂排列顺序一致；Start measure 与动态显示其锚定小节编号的勾选框放在下一行，原厂其余占位控件补齐时再对齐完整垂直分组。复现确认：勾选时等距尺标标签间隔以工程起始小节为相位，取消后以小节 1 为相位。本页当前编辑起始 BPM、起始拍号、显示小节号、BPM basis 和尺标标签间隔基准；变更只存工程草稿，OK 通过 `SetTempo {start_tick:0}`、`SetTimeSignature {start_tick:0}`、`SetProjectStartMeasure`、`SetProjectBpmBasis` 与 `SetBaseRulerLabelSpacingOnMeasure` 一次事务提交，Cancel 丢弃。速度须为有限正数，拍号须是当前 PPQ 可表示的正整数，小节号接受有符号 32 位整数；原厂与 AAADAW 实测 0 和 -2 均可保存，超出范围的输入保持窗口与草稿并让工程不变。BPM basis 提供原厂六个选项：1/8、1/4、1/2、1/8 dotted、1/4 dotted、1/2 dotted；默认 1/4。显示 BPM 数字不变，所选音符值决定每分钟的拍数，因此会改变刻度与音频时间之间的换算。合法联合提交可一次 Undo。负小节号也贯通 Beats 位置格式化/解析与时间线标尺。

有限控制集反映已接入的项目状态，不虚列不可用控件。General 尚有原厂 sample rate/whole-sample 强制、project/track/item timebase、MIDI timebase、project start time、playback/render resampling、pitch shift mode/parameters；这些依赖采样时钟/timebase和工程配置，不在此阶段冒充完成。新配置 REAPER ReaScript 探针确认 sample rate 44100 且未强制、工程 item timebase 代码值 1（Beats: position, length, rate）、timebase flags 0、项目起点偏移 0、起始 120 BPM 与 4/4。其余屏幕值见[数值记录](project-settings-general-reference.json)。视频页显示预设值与非原厂输入仍待实施；Media、Advanced、模板和其余设置页继续按 P10 推进。

真实 AAADAW X11 验证：默认 120/4/4/1、basis 1/4 且 ruler-spacing 开启；编辑 96/3/8/-2、basis 1/8 并关闭 ruler-spacing 时工程保持不变；OK 后重新打开读取新值；关闭窗口后在主窗口 Ctrl+Z 一次还原全部 General 设置；关闭模式下缩放标尺显示从 measure 1 开始的间隔标签。Start measure=0 可提交并重开读取，Ctrl+Z 还原；Start measure 超出有符号 32 位范围时 OK 不关闭窗口，工程不变。BPM 0 和不适用拍号也会被拒绝。六个 basis 选项与原厂顺序相同，1/8 下仍显示 120 BPM，四分音符时钟速率减半，4/4 小节时长由 2 秒变为 4 秒；basis 调整后的 tempo ramp sample/tick 往返也由 Core 回归覆盖。原厂 ReaScript 探针确认工厂初始值；原厂 General 窗口另行确认 0 和 -2 可保存，且基准尺标签跟随显示 -2。证据截图仅来自 AAADAW：[默认](../verification/reaper-parity/project-settings-ui/general-default.png)、[六项 BPM basis](../verification/reaper-parity/project-settings-ui/general-bpm-basis-options.png)、[草稿](../verification/reaper-parity/project-settings-ui/general-draft.png)、[确认后](../verification/reaper-parity/project-settings-ui/general-after-apply.png)、[ruler-spacing 关闭草稿](../verification/reaper-parity/project-settings-ui/general-ruler-spacing-off.png)、[关闭后的标尺](../verification/reaper-parity/project-settings-ui/general-ruler-spacing-off-main.png)、[撤销后](../verification/reaper-parity/project-settings-ui/general-real-undo.png)、[零小节](../verification/reaper-parity/project-settings-ui/general-zero-start-measure.png)、[拒绝越界输入](../verification/reaper-parity/project-settings-ui/general-invalid-result.png)。本阶段不提交 REAPER 原厂截图或工程。
