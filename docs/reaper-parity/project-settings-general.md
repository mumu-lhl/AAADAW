# Project Settings General（阶段实现）

固定参照 Linux REAPER 7.82 / Default 7 / factory。General 页原厂默认 BPM 120、Time signature 4/4、Project start time `0:00.000`、Start measure 1、BPM basis 1/4、Base ruler label spacing 开启，与[原厂设置窗口的数值记录](project-settings-general-reference.json)互证。AAADAW 将 BPM、拍号和 BPM basis 放在同一行；Project start time 在下一行，Start measure 与动态显示其锚定小节编号的勾选框再下一行。原厂其他占位控件补齐时再对齐完整垂直分组。复现确认：勾选时等距尺标标签间隔以工程起始小节为相位，取消后以小节 1 为相位。

本页现编辑起始 BPM、起始拍号、有符号显示小节号、BPM basis、尺标标签间隔基准和有符号 Project start time。Project start time 是显示时钟偏移，不移动音频采样位置或改变小节/拍换算；它平移时间线时钟、Transport 时钟与 Item Properties 的 Time/H:M:S:F 绝对位置显示。OK 将所有有变化的 General 字段通过单一事务提交：tempo、拍号、`SetProjectStartMeasure`、`SetProjectBpmBasis`、`SetBaseRulerLabelSpacingOnMeasure` 与 `SetProjectStartTimeOffsetSeconds`；Cancel 丢弃草稿。旧工程 schema 31 迁移为零偏移，当前 schema 为 32。

速度须为有限正数，拍号须是当前 PPQ 可表示的正整数，小节号接受有符号 32 位整数；原厂与 AAADAW 实测 0 和 -2 均可保存。时间输入支持带符号的 `m:ss.mmm` 与 `h:mm:ss.mmm`；分钟/秒字段要求小于 60，非法值保持窗口与草稿，且不会部分应用其他 General 项。BPM basis 提供原厂六个选项：1/8、1/4、1/2、1/8 dotted、1/4 dotted、1/2 dotted；默认 1/4。显示 BPM 数字不变，所选音符值决定每分钟的拍数，因此会改变刻度与音频时间之间的换算。合法联合提交可一次 Undo。负小节号也贯通 Beats 位置格式化/解析与时间线标尺。

有限控制集反映已接入的项目状态，不虚列不可用控件。General 尚有原厂 sample rate/whole-sample 强制、project/track/item timebase、MIDI timebase、playback/render resampling、pitch shift mode/parameters；这些依赖采样时钟、timebase 和工程配置，不在此阶段冒充完成。新配置 REAPER ReaScript 探针确认 sample rate 44100 且未强制、工程 item timebase 代码值 1（Beats: position, length, rate）、timebase flags 0、项目起点偏移 0、起始 120 BPM 与 4/4。其余屏幕值见[数值记录](project-settings-general-reference.json)。视频页显示预设值与非原厂输入仍待实施；Media、Advanced、模板和其余设置页继续按 P10 推进。

REAPER 原厂 General 验证设置 `0:10.000` 将 Transport 与尺标时间平移 10 秒但不改变小节，负偏移 `-0:05.000` 也被接受。真实 AAADAW X11 验证默认值、编辑 `96/3/8/-2`、basis 1/8、偏移 `-0:05.000` 并关闭 ruler-spacing 时工程仍保持原值；OK 后重开读取草稿，Transport/尺标时钟显示负 5 秒，关闭窗口后一次 Ctrl+Z 还原全部 General 设置。Start measure=0 可提交并重开；无效时间 `0:60.000` 点 OK 后窗口保留且工程不变，事务测试也验证不会部分提交速度/拍号。时间偏移格式/反解析、Item Properties Time/H:M:S:F 偏移与逆向输入、帧率换算、schema 31 默认迁移及存储 round-trip 均有回归。六项 basis 选项与原厂顺序相同；相关时钟换算与 tempo ramp sample/tick 往返由 Core 覆盖。证据截图仅来自 AAADAW：[默认](../verification/reaper-parity/project-settings-ui/general-default.png)、[六项 BPM basis](../verification/reaper-parity/project-settings-ui/general-bpm-basis-options.png)、[草稿](../verification/reaper-parity/project-settings-ui/general-draft.png)、[确认后](../verification/reaper-parity/project-settings-ui/general-after-apply.png)、[ruler-spacing 关闭草稿](../verification/reaper-parity/project-settings-ui/general-ruler-spacing-off.png)、[关闭后的标尺](../verification/reaper-parity/project-settings-ui/general-ruler-spacing-off-main.png)、[撤销后](../verification/reaper-parity/project-settings-ui/general-real-undo.png)、[零小节](../verification/reaper-parity/project-settings-ui/general-zero-start-measure.png)、[拒绝无效时间](../verification/reaper-parity/project-settings-ui/general-invalid-result.png)。本阶段不提交 REAPER 原厂截图或工程。
