# Project Settings General（阶段实现）

固定参照 Linux REAPER 7.82 / Default 7 / factory。AAADAW 第一页签现在使用原厂标签 `Project Settings`；当前只实现了其 General 子集，原厂 Media 与 Advanced 页签及完整设置仍缺。General 页原厂默认 BPM 120、Time signature 4/4、Project start time `0:00.000`、Start measure 1、BPM basis 1/4、Base ruler label spacing 开启，与[原厂设置窗口的数值记录](project-settings-general-reference.json)互证。AAADAW 将 BPM、拍号和 BPM basis 放在同一行；Project start time 在下一行，Start measure 与动态显示其锚定小节编号的勾选框再下一行。原厂其他控件补齐时再对齐完整垂直分组。复现确认：勾选时等距尺标标签间隔以工程起始小节为相位，取消后以小节 1 为相位。

起始时间/小节弹出菜单的 AAADAW 界面证据：[默认未勾选](../verification/reaper-parity/project-settings-ui/general-start-time-menu.png)与[勾选 fractional-frame 选项](../verification/reaper-parity/project-settings-ui/general-start-time-menu-fractional-frame-on.png)。

本页现编辑起始 BPM、起始拍号、有符号显示小节号、BPM basis、尺标标签间隔基准、有符号 Project start time，以及显式工程采样率和 whole-sample tempo-map 选项。Project start time 是显示时钟偏移，不移动音频采样位置或改变小节/拍换算；它平移时间线时钟、Transport 时钟与 Item Properties 的 Time/H:M:S:F 绝对位置显示。`Change start time/measure...` 菜单提供原厂前四项：将当前编辑光标设为 `0:00`、重置工程起始时间、将当前光标最近的小节设为小节 1、重置工程起始小节；第五项允许工程起点处于 fractional-frame offset，默认关闭并显示勾选状态。Up/Down 循环、Enter 执行、Escape 关闭。菜单命令只更新 General 草稿，仍由 OK 统一提交，Cancel 丢弃。OK 将所有有变化的 General 字段通过单一事务提交；Cancel 丢弃草稿。旧工程会迁移出默认关闭的 fractional-frame 与 whole-sample 字段，当前 schema 为 34。

General 现在提供原厂下拉框的 11 个显式工程采样率：8,000、11,025、16,000、22,050、32,000、44,100、48,000、88,200、96,000、176,400、192,000 Hz；当前非预设值仍作为额外选项显示。原厂菜单见[采样率列表截图](../verification/reaper-parity/project-settings-ui/reaper-native-sample-rate-options.png)。`SetProjectSampleRate` 会在单一工程动作中按采样率比例换算音频 Item 的位置/长度和 fade、轨道音量与 CLAP 参数自动化的位置，并重算 TempoMap 的 sample anchor；媒体源偏移仍按源文件采样率计。事务期间播放图会标脏，在下次启动时重建，Transport/playback 起点也会同步换算。Undo/Redo 精确恢复转换前后值，工程快照沿用既有 sample-rate 字段，无需新增 schema。自动化点在新速率下无法保持唯一位置或工程内容超出时间线可表示范围时，整个 Action 会失败，不会静默丢点。Xvfb GUI 实测选项列表、选择 44.1 kHz 后重开读取，以及 Edit > Undo 恢复原 48 kHz；[四张 AAADAW 截图](../verification/reaper-parity/project-settings-ui/general-project-sample-rate.png)记录默认、候选速率、应用后和撤销后状态。

`Save as default project settings` 会先通过与 OK 相同的校验和提交路径应用当前草稿，再原子保存受支持的项目设置到用户配置 `default-project-settings.json`；按钮保存成功后保持 Project Settings 窗口打开。下次启动和 File > New project 会应用这些默认值。新工程只继承当前已接入的 BPM、拍号、采样率、BPM basis、Start measure、ruler spacing、whole-sample、project start time、fractional-frame 和视频帧率，不复制轨道、Item、媒体、MIDI、工程备注或撤销记录。格式版本和字段在加载时验证；文件缺失时回落内置默认值，文件无效时保留原文件并报告状态。Xvfb 实窗将 120/4/4 改为 96/7/8 并按该按钮保存，应用重启与 File > New project 后均重新读取该值；见[默认设置按钮](../verification/reaper-parity/project-settings-ui/general-save-default-project-settings.png)和[新工程加载结果](../verification/reaper-parity/project-settings-ui/general-default-settings-new-project.png)。该功能为 AAADAW 用户默认设置闭环，尚不代表 REAPER 的完整模板系统或未实现的项目选项已纳入默认模板。

`Force project tempo/time signature changes to occur on whole samples` 已通过 Core Action 接入 General 草稿、事务、Undo/Redo、TempoMap 锚点和 schema 34。启用后重算 tempo-map 时每个 tempo point 连续 sample anchor 会取整到最近的工程样本；44.1 kHz、120 BPM、PPQ 960 下 tick 1 的 anchor 从 22.96875 变为 23.0。原厂 REAPER 工程对照显示 `SAMPLERATE` 三字段分别包含 44.1 kHz、project-rate enabled 与 whole-sample enabled：fresh factory 为 `44100 0 0`，仅开启工程采样率为 `44100 1 0`，两个选项都开启为 `44100 1 1`。参考截图见[factory 默认](../verification/reaper-parity/project-settings-ui/reaper-native-general-factory.png)和[whole-sample checked](../verification/reaper-parity/project-settings-ui/reaper-native-general-whole-samples-checked.png)；AAADAW 的[勾选状态](../verification/reaper-parity/project-settings-ui/general-whole-sample-checked.png)与[撤销后恢复](../verification/reaper-parity/project-settings-ui/general-whole-sample-after-undo.png)也已在 X11 实窗复核。原厂 UI marker-edit snapping 与 meter-marker 的具体边界效果仍待进一步确认；本实现不把该设置描述成完整 REAPER snapping 行为。

速度须为有限正数，拍号须是当前 PPQ 可表示的正整数，小节号接受有符号 32 位整数；原厂与 AAADAW 实测 0 和 -2 均可保存。时间输入支持带符号的 `m:ss.mmm` 与 `h:mm:ss.mmm`；分钟/秒字段要求小于 60，非法值保持窗口与草稿，且不会部分应用其他 General 项。BPM basis 提供原厂六个选项：1/8、1/4、1/2、1/8 dotted、1/4 dotted、1/2 dotted；默认 1/4。显示 BPM 数字不变，所选音符值决定每分钟的拍数，因此会改变刻度与音频时间之间的换算。合法联合提交可一次 Undo。负小节号也贯通 Beats 位置格式化/解析与时间线标尺。

有限控制集反映已接入的项目状态，不虚列不可用控件。fractional-frame flag 的默认值和 RPP `TIMEMODE` 存储已核实；精确 flag 对视频帧与 H:M:S:F 的对齐影响仍待测量。采样率已实现显式工程速率和原厂完整预设列表，但还缺原厂默认关闭的 project-rate checkbox 与 hardware-default 联动；factory REAPER 当前配置为 44.1 kHz 且未强制，AAADAW 新工程目前为 48 kHz。project/track/item timebase、MIDI timebase、General 的重采样模式选择与工程持久化、其他 render 选项，以及 pitch shift mode/parameters 仍待实现。AAADAW 媒体 worker 已接入 64-tap Blackman-windowed sinc 播放与 WAV export/Freeze 的 192-tap 离线路径，并验证抗混叠和过渡带差异，但尚未比对 REAPER 的具体滤波系数；见[播放重采样验证记录](../verification/reaper-parity/project-playback-resampling.md)与[原厂菜单截图](../verification/reaper-parity/project-settings-ui/reaper-native-playback-resampling-options.png)。这些完整行为依赖采样时钟、timebase 和工程配置。新配置 REAPER ReaScript 探针还确认工程 item timebase 代码值 1（Beats: position, length, rate）、timebase flags 0、项目起点偏移 0、起始 120 BPM 与 4/4。其余屏幕值见[数值记录](project-settings-general-reference.json)。视频页显示预设值与非原厂输入仍待实施；Media、Advanced 和 REAPER 完整工程模板系统继续按 P10 推进。AAADAW 的 `Save as default project settings` 只持久化上述已实现字段。

REAPER 原厂 General 验证设置 `0:10.000` 将 Transport 与尺标时间平移 10 秒但不改变小节，负偏移 `-0:05.000` 也被接受。真实 AAADAW X11 验证默认值、编辑 `96/3/8/-2`、basis 1/8、偏移 `-0:05.000` 并关闭 ruler-spacing 时工程仍保持原值；OK 后重开读取草稿，Transport/尺标时钟显示负 5 秒，关闭窗口后一次 Ctrl+Z 还原全部 General 设置。Start measure=0 可提交并重开；无效时间 `0:60.000` 点 OK 后窗口保留且工程不变，事务测试也验证不会部分提交速度/拍号。时间偏移格式/反解析、Item Properties Time/H:M:S:F 偏移与逆向输入、帧率换算、schema 31 默认迁移及存储 round-trip 均有回归。六项 basis 选项与原厂顺序相同；相关时钟换算与 tempo ramp sample/tick 往返由 Core 覆盖。证据截图仅来自 AAADAW：[默认](../verification/reaper-parity/project-settings-ui/general-default.png)、[六项 BPM basis](../verification/reaper-parity/project-settings-ui/general-bpm-basis-options.png)、[草稿](../verification/reaper-parity/project-settings-ui/general-draft.png)、[确认后](../verification/reaper-parity/project-settings-ui/general-after-apply.png)、[ruler-spacing 关闭草稿](../verification/reaper-parity/project-settings-ui/general-ruler-spacing-off.png)、[关闭后的标尺](../verification/reaper-parity/project-settings-ui/general-ruler-spacing-off-main.png)、[撤销后](../verification/reaper-parity/project-settings-ui/general-real-undo.png)、[零小节](../verification/reaper-parity/project-settings-ui/general-zero-start-measure.png)、[拒绝无效时间](../verification/reaper-parity/project-settings-ui/general-invalid-result.png)。本阶段不提交 REAPER 原厂截图或工程。
