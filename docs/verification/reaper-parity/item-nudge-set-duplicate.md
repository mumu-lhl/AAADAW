# Nudge/Set → Duplicate

Linux REAPER `7.82/linux-x86_64` with the Default 7 theme was opened in a fresh unsaved project. A selected loop-source MIDI item at 3.900 seconds contained two notes. In the real 528×121 dialog, Mode was `Set`, Target was `duplicate`, the absolute target was 4.150 seconds, and Snap was off. Apply kept the original at 3.900 seconds, created a same-length copy at 4.150 seconds, and selected only the copy. Its loop flag, source offset, and note PPQ matched the original. One Undo removed the copy and restored the original selection; Redo recreated and selected the copy. The [native TSV](fixtures/item-nudge-midi-set-duplicate-native.tsv) and [before](fixtures/item-nudge-midi-set-duplicate-native-before.png), [after](fixtures/item-nudge-midi-set-duplicate-native-after.png), [Undo](fixtures/item-nudge-midi-set-duplicate-native-undo.png), and [Redo](fixtures/item-nudge-midi-set-duplicate-native-redo.png) captures preserve the result.

Two additional native settings were measured. With `Relative Set` checked, the target value remained absolute: `0.250` seconds created a copy at 0.250 seconds. With Snap enabled in the `minutes:seconds` unit, target 4.150 seconds rounded to 4.000 seconds and selected that copy.

AAADAW now applies Set → Duplicate to selected Audio and MIDI items as one transaction. It uses the first item by timeline position as the placement anchor, retains the relative spacing of the selected items, rounds the anchor target when Snap is enabled, and selects only the copies. The App regressions cover mixed Audio/MIDI copies, note and source preservation, Snap rounding, the observed Relative Set behavior, and one-step Undo/Redo.

The current worktree desktop binary was built with nightly Cranelift (SHA-256 `25cf7e4bde6e061c52bead045b5fae18e2493b0d45fb2d402e30634fb0d0a0b1`).
