# MIDI Event Filter: Parameter and Value

Reference: Linux REAPER 7.82, Default 7 theme. The native Filter Events dialog exposes a Control parameter and an inclusive Value low/high range for Control Change events.

The isolated native probe creates three Notes and four CCs: CC7 values 64 and 100, CC10 value 64, and CC7 value 127. With Show-only enabled, Event type set to Control Change, Control set to `07 Volume MSB`, and Value set to `64`–`100`, REAPER leaves exactly the CC7 rows with values 64 and 100 visible. The CC10 row and CC7 value 127 are hidden; notes and the synthetic end row are hidden. The native MIDI readback, saved `EVTFILTER` project state, screenshots, and REAPER binary identity are recorded in the [native fixture manifest](fixtures/midi-event-filter-cc-native.tsv). The probe can be regenerated with [probe-midi-event-filter-cc.lua](../../../scripts/reaper_parity/probe-midi-event-filter-cc.lua); the filter dialog values are set interactively as described in the script.

AAADAW models the selected CC parameter and inclusive 0–127 Value range in the same filter criteria used by the Event List, controller-lane visibility/hit testing, and Set/Add/Remove selection operations. The Filter Events dialog presents the native-named controller choices and low/high values when Control Change is selected. Invalid or incomplete numeric values do not change the stored range; valid bounds are kept ordered. Clear filter resets these criteria. The app regression sends the UI messages, verifies that the two boundary values pass while other parameter/value combinations do not, and confirms filtering leaves the MIDI project snapshot unchanged. Earlier Xvfb screenshots, project source, binary identity, and hashes are in the [AAADAW fixture manifest](fixtures/midi-event-filter-cc-aaadaw.tsv); that row-count capture predates the separate Event List Filter toggle. Current real-window toggle behavior is recorded in the [mixed-CC manifest](fixtures/midi-event-filter-from-mixed-cc-aaadaw.tsv).

This is a measured CC7/value slice, not complete Filter Events parity. Native reset behavior for Control and Value, parameter/value behavior with Invert, CC0/32 Bank Select pairing, and other controller parameters remain open. Mixed-parameter Set filter from selection is now measured: Control becomes disabled/<all>, while the selected CC values and positions still define inclusive Value and Position ranges; see the [mixed CC selection record](midi-event-filter-from-selection.md). Set filter from selection activates the Event List filter while preserving Show-only off; enabling Show-only also activates the Event List filter, and disabling its funnel clears Show-only. The [filter-toggle capture](fixtures/midi-event-filter-toggle-native.tsv) records this relationship. Note and CC Position/Repeat matching is documented in the [Position and Repeat record](midi-event-filter-position-repeat.md). Position filtering for the remaining modeled event types, Length for non-Notes, and Solo remain open; the type/category and channel criteria are described in the [Event List record](midi-event-list.md).
