# MIDI Editor Quantize Events dialog

Linux REAPER 7.82 / Default 7 action 40009 opens `Quantize Events`. Its captured defaults are `Settings: Use grid`, `Quantize: Selected notes`, operation `Position`, and Strength `100%`; `Bypass` is unchecked and `Fix overlaps` is checked. The scope menu offers All notes, Selected notes, All events, and Selected events in that order. The operation menu offers Position, Position and note end, Position and note length, Note end only, and Note length only. The native dialog and both option menus are captured in the [fixture manifest](fixtures/midi-quantize-dialog-ui.tsv).

AAADAW adds `Quantize…` to the desktop MIDI Editor toolbar. Its modal uses the current MIDI Editor grid and supports All notes, Selected notes, All events, or Selected events in the native menu order for notes, CC, Pitch Bend, Program Change, Poly Aftertouch, Channel Pressure, and opaque SysEx/Meta events; all five native note operations (Position, Position and note end, Position and note length, Note end only, and Note length only); 0–100% strength; Fix overlaps (checked by default); and Bypass. The MIDI Editor selects CC, Pitch Bend, Program Change, Poly Aftertouch, Channel Pressure, and opaque SysEx/Meta rows by clicking; Ctrl/Command-click toggles additive selection. Fix overlaps trims a quantized note to the next note start with the same channel and pitch, and can also shorten an unselected earlier note that overlaps the quantized note. Bypass is off by default; when enabled, Commit makes no edit and keeps the dialog open, while OK makes no edit and closes it. Cancel and Escape discard pending dialog settings while keeping any earlier committed edit. Notes in the all-notes scope include notes hidden by the editor channel filter. Direct `Q pos` and `Q pos+end` toolbar actions remain available.

The operation math was checked against REAPER 7.82 at 100% on a 1/32 grid (120 PPQ ticks): Position moves starts and preserves lengths; Position and note end independently snaps both endpoints; Position and note length snaps starts and durations; Note end only preserves starts and snaps ends; Note length only preserves starts and snaps durations. A positive-strength note-length quantize keeps at least one grid interval when a very short note would otherwise round to zero. A distinguishing `100–280` note becomes `120–360` under Position and note length, while Note end only yields `100–240`; the unselected `550–670` note is unchanged. The exact event readbacks are in the [native operation probe](fixtures/midi-quantize-operations-native.tsv).

REAPER's 50% strength result was also measured on the 1/32 grid. Selected starts `170`, `350`, and `900` become `145`, `355`, and `930`; the `550` unselected start remains unchanged, and all durations are preserved. This matches AAADAW's midpoint interpolation. The [native result](fixtures/midi-quantize-strength-native.tsv) and [50% dialog capture](fixtures/midi-quantize-strength-50-reaper-native.png) record the comparison.

The native All events scope was measured with selected and unselected notes, CC, and Pitch Bend events. Position quantize moved every measured event to the grid while preserving note lengths, event values, channels, and selection state. AAADAW applies the same operation across those three event types as a single undoable transaction; the [native event readback](fixtures/midi-quantize-all-events-native.tsv) records the exact ticks. A second native probe placed two CC1 events and two Pitch Bend events close enough to collide after quantizing. REAPER retained the same-channel CC event with the later original tick and its value, and did the same for same-channel Pitch Bend events; AAADAW now produces the same merged result, and one Undo restores every original event. The exact readback is in the [collision fixture](fixtures/midi-quantize-all-events-collisions-native.tsv). AAADAW also applies All events to Program Change, Poly Aftertouch, Channel Pressure, SysEx, and Meta events. New REAPER 7.82 probes confirm that All events quantizes text Meta and F0 SysEx and retains both same-tick duplicates with their payloads and selection flags intact; exact readbacks and dialog captures are in the [opaque fixtures](fixtures/midi-quantize-opaque-all-native.tsv) and [dialog capture](fixtures/midi-quantize-opaque-all-reaper-native.png). New REAPER 7.82 All events and Selected events probes now measure Program Change, Poly Aftertouch, and Channel Pressure on the same 1/32 straight grid. In both scopes, a selected Program Change and selected Channel Pressure at 475 move to 480 and take the single channel/tick slot from the unselected event already there. Poly Aftertouch behaves differently: a selected value 80 at 355 moves to 360 while unselected value 90 at 360 remains beside it, including in All events. Unrelated modeled events move only in All events; selected-state flags are preserved. The [modeled-event readbacks](fixtures/midi-quantize-modeled-all-native.tsv) and [All events capture](fixtures/midi-quantize-modeled-all-reaper-native.png), [Selected events readback](fixtures/midi-quantize-modeled-selected-native.tsv) and [capture](fixtures/midi-quantize-modeled-selected-reaper-native.png), and [reproducible probe](../../../scripts/reaper_parity/probe-midi-quantize-dialog-modeled-events.lua) record the settings and results.

Selected events was measured with one selected note, one selected CC, and one selected Pitch Bend alongside unselected events. On a straight 1/32 grid, selected note `170–260` became `120–210`, while unselected notes stayed at `350–430` and `550–670`; selected CC1 at `475` moved to `480`, and selected Pitch Bend at `835` moved to `840`. In deliberate collisions with unselected CC1 at `480` and Pitch Bend at `840`, REAPER kept the selected event and removed the unselected one, even though the unselected event had the later original tick. Selection flags remained set. AAADAW uses selected-event priority in Selected events and carries the current CC, Pitch Bend, Program Change, and Channel Pressure selection into All events collision resolution; when no selected event participates, it keeps the later original event as recorded in the All-events CC/Pitch Bend probe. The scope list follows the native order, and a live Xvfb click on the final menu item keeps the dialog open with Selected events selected. Applying the scope to an off-grid CC1 point visibly moves only that selected point onto the grid and preserves its selected highlight. Fix overlaps was measured with three same-channel, same-pitch notes and Position and note length at 100%. After the MIDI editor loaded, the pre-quantize notes read back as `100–300`, `180–300`, and `330–350`. With the native default checked, the quantized output was `120–240`, `240–360`, and `360–480`; with the checkbox off, the first note remained `120–360` and overlapped the second note at `240–360`. A separate two-note Selected notes probe showed the checked option shortens the unselected first note from `100–300` to `100–240`, while the selected note becomes `240–360`. The unchecked `MIDI_GetNote` readback reports the selected row as `240–300`, but raw-event probes show that selected NoteOff events move with their selected notes; when same-key overlaps make note-off ownership ambiguous, `MIDI_GetNote` can report that endpoint under another row. AAADAW now preserves the selected note's quantized duration and leaves unselected note endpoints intact when Fix overlaps is off. Exact REAPER readbacks and checked/unchecked captures are recorded in the [Fix overlaps fixture](fixtures/midi-quantize-fix-overlaps-native.tsv). Regressions also cover All notes behavior, minimum note length, and Undo/Redo.

A longer Selected notes probe with Fix overlaps off measured a five-note same-pitch chain for Position and note length. The selected note starts at `180`, moves to `240`, and its selected raw NoteOff moves from `300` to `360`; the same-tick-key `MIDI_GetNote` pairing reports the selected row as `240–300` and the next unselected row as `330–360`. This is a readback pairing artifact: the raw selected NoteOff follows its selected note, and the unselected NoteOff at `480` does not move. A new seven-note probe selects notes 2 and 4 while their quantized NoteOffs cross several unselected same-key notes: raw selected NoteOffs move to `360` and `720`, and every unselected NoteOff stays at `300`, `480`, `650`, `760`, or `880`. AAADAW now quantizes each selected note's own start and end without changing neighboring note endpoints when Fix overlaps is off. Quantize Events also follows the active MIDI Editor Swing grid. On REAPER 7.82 with a 1/32 grid, 50% swing, and 960 PPQ per quarter note, odd grid points move 30 ticks later: selected starts `170` and `350` quantize to `150` and `390`, while an unselected note at `550` stays put in Selected notes scope. The exact midpoint at tick `75` resolves to the later point `150`. Position and note length uses those swung points for note starts but keeps note lengths on the straight 120-tick grid; Position and note end snaps both endpoints to swing points. All events also applies the swung grid to unselected notes, CC, and Pitch Bend, and same-tick CC/Pitch Bend collisions retain the event with the latest original tick. This remains a partial implementation. Native Position behavior and same-position collision rules are now measured for Program Change, Poly Aftertouch, and Channel Pressure on a straight 1/32 grid; other grid, Swing, strength, and timing-operation combinations remain open. Meta and F0 SysEx positions, duplicate retention, selected-event behavior, and payload/selection preservation are measured. Unmatched standalone F7 does not survive the native take readback and cannot be compared as an independent quantized row. Other mixed-selection same-key overlap layouts, further Fix overlaps cases, and remembered dialog settings remain open. These broader gaps remain in progress in the parity matrix.
