# MIDI Editor Quantize Events dialog

Linux REAPER 7.82 / Default 7 action 40009 opens `Quantize Events`. Its captured defaults are `Settings: Use grid`, `Quantize: Selected notes`, operation `Position`, and Strength `100%`; `Bypass` is unchecked and `Fix overlaps` is checked. The scope menu offers All notes, Selected notes, All events, and Selected events. The operation menu offers Position, Position and note end, Position and note length, Note end only, and Note length only. The native dialog and both option menus are captured in the [fixture manifest](fixtures/midi-quantize-dialog-ui.tsv).

AAADAW adds `Quantize…` to the desktop MIDI Editor toolbar. Its modal uses the current MIDI Editor grid and supports All notes, Selected notes, or All events for the currently modeled note, CC, and Pitch Bend event types; all five native note operations (Position, Position and note end, Position and note length, Note end only, and Note length only); and 0–100% strength. Commit applies one undoable edit and leaves the dialog open; OK applies and closes it; Cancel and Escape discard pending dialog settings while keeping any earlier committed edit. Notes in the all-notes scope include notes hidden by the editor channel filter. Direct `Q pos` and `Q pos+end` toolbar actions remain available.

The operation math was checked against REAPER 7.82 at 100% on a 1/32 grid (120 PPQ ticks): Position moves starts and preserves lengths; Position and note end independently snaps both endpoints; Position and note length snaps starts and durations; Note end only preserves starts and snaps ends; Note length only preserves starts and snaps durations. A distinguishing `100–280` note becomes `120–360` under Position and note length, while Note end only yields `100–240`; the unselected `550–670` note is unchanged. The exact event readbacks are in the [native operation probe](fixtures/midi-quantize-operations-native.tsv).

REAPER's 50% strength result was also measured on the 1/32 grid. Selected starts `170`, `350`, and `900` become `145`, `355`, and `930`; the `550` unselected start remains unchanged, and all durations are preserved. This matches AAADAW's midpoint interpolation. The [native result](fixtures/midi-quantize-strength-native.tsv) and [50% dialog capture](fixtures/midi-quantize-strength-50-reaper-native.png) record the comparison.

The native All events scope was measured with selected and unselected notes, CC, and Pitch Bend events. Position quantize moved every modeled event to the grid while preserving note lengths, event values, channels, and selection state. AAADAW applies the same operation across those three event types as a single undoable transaction; the [native event readback](fixtures/midi-quantize-all-events-native.tsv) records the exact ticks. A second native probe placed two CC1 events and two Pitch Bend events close enough to collide after quantizing. REAPER retained the same-channel CC event with the later original tick and its value, and did the same for same-channel Pitch Bend events; AAADAW now produces the same merged result, and one Undo restores every original event. The exact readback is in the [collision fixture](fixtures/midi-quantize-all-events-collisions-native.tsv).

A live interaction selected All notes and Position and note end at 100% on the 1/32 grid; the [configured dialog](fixtures/midi-quantize-dialog-all-note-ends-aaadaw.png) and [post-apply capture](fixtures/midi-quantize-dialog-apply-aaadaw.png) show the operation and resulting editor status. App regressions verify defaults, native-matched 50% strength interpolation, all three implemented scopes, note-length-only selection, collision merging, Commit, Cancel/Escape, and one-step Undo/Redo for each Core operation.

This remains a partial implementation. Selected events, Program Change, channel pressure, SysEx and other unmodeled MIDI event types, Bypass, Fix overlaps behavior, swing-grid intersection, and remembered dialog settings are not exposed or implemented. These gaps remain in progress in the parity matrix.
