# MIDI Editor Quantize Events dialog

Linux REAPER 7.82 / Default 7 action 40009 opens `Quantize Events`. Its captured defaults are `Settings: Use grid`, `Quantize: Selected notes`, operation `Position`, and Strength `100%`; `Bypass` is unchecked and `Fix overlaps` is checked. The scope menu offers All notes, Selected notes, All events, and Selected events. The operation menu offers Position, Position and note end, Position and note length, Note end only, and Note length only. The native dialog and both option menus are captured in the [fixture manifest](fixtures/midi-quantize-dialog-ui.tsv).

AAADAW adds `Quantize…` to the desktop MIDI Editor toolbar. Its modal uses the current MIDI Editor grid and supports All notes or Selected notes, all five native note operations (Position, Position and note end, Position and note length, Note end only, and Note length only), and 0–100% strength. Commit applies one undoable edit and leaves the dialog open; OK applies and closes it; Cancel and Escape discard pending dialog settings while keeping any earlier committed edit. Notes in the all-notes scope include notes hidden by the editor channel filter. Direct `Q pos` and `Q pos+end` toolbar actions remain available.

The operation math was checked against REAPER 7.82 at 100% on a 1/32 grid (120 PPQ ticks): Position moves starts and preserves lengths; Position and note end independently snaps both endpoints; Position and note length snaps starts and durations; Note end only preserves starts and snaps ends; Note length only preserves starts and snaps durations. A distinguishing `100–280` note becomes `120–360` under Position and note length, while Note end only yields `100–240`; the unselected `550–670` note is unchanged. The exact event readbacks are in the [native operation probe](fixtures/midi-quantize-operations-native.tsv).

The [live AAADAW capture](fixtures/midi-quantize-dialog-aaadaw.png) shows the default dialog, and the [scope](fixtures/midi-quantize-scope-menu-aaadaw.png) and [operation](fixtures/midi-quantize-operation-menu-aaadaw.png) menu captures show the available options. A separate [Note length only capture](fixtures/midi-quantize-dialog-note-length-only-aaadaw.png) records selecting that native mode in the live dialog. A live interaction selected All notes and Position and note end at 100% on the 1/32 grid; the [configured dialog](fixtures/midi-quantize-dialog-all-note-ends-aaadaw.png) and [post-apply capture](fixtures/midi-quantize-dialog-apply-aaadaw.png) show the operation and resulting editor status. App regressions verify defaults, 50% strength interpolation, selected/all-note scope, note-length-only selection, Commit, Cancel/Escape, and one-step Undo/Redo for each Core operation.

This remains a partial implementation. All events and Selected events, Bypass, Fix overlaps behavior, swing-grid intersection, and remembered dialog settings are not exposed or implemented. The native strength slider and default were captured, but native 50% quantization output has not been measured; AAADAW's strength path is covered by app regression only. These gaps remain in progress in the parity matrix.
