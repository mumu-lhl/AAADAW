# MIDI Editor Quantize Events dialog

Linux REAPER 7.82 / Default 7 action 40009 opens `Quantize Events`. Its captured defaults are `Settings: Use grid`, `Quantize: Selected notes`, operation `Position`, and Strength `100%`; `Bypass` is unchecked and `Fix overlaps` is checked. The scope menu offers All notes, Selected notes, All events, and Selected events. The operation menu offers Position, Position and note end, Position and note length, Note end only, and Note length only. The native dialog and both option menus are captured in the [fixture manifest](fixtures/midi-quantize-dialog-ui.tsv).

AAADAW adds `Quantize…` to the desktop MIDI Editor toolbar. Its modal uses the current MIDI Editor grid and supports All notes or Selected notes, Position or Position and note end, and 0–100% strength. Commit applies one undoable edit and leaves the dialog open; OK applies and closes it; Cancel and Escape discard pending dialog settings while keeping any earlier committed edit. Notes in the all-notes scope include notes hidden by the editor channel filter. Direct `Q pos` and `Q pos+end` toolbar actions remain available.

The [live AAADAW capture](fixtures/midi-quantize-dialog-aaadaw.png) shows the default dialog, and the [scope](fixtures/midi-quantize-scope-menu-aaadaw.png) and [operation](fixtures/midi-quantize-operation-menu-aaadaw.png) menu captures show the available implemented options. A live interaction selected All notes and Position and note end at 100% on the 1/32 grid; the [configured dialog](fixtures/midi-quantize-dialog-all-note-ends-aaadaw.png) and [post-apply capture](fixtures/midi-quantize-dialog-apply-aaadaw.png) show the operation and resulting editor status. App regressions verify defaults, 50% strength interpolation, selected/all-note scope, Commit, Cancel/Escape, and one-step Undo/Redo.

This is a deliberate partial implementation. All events and Selected events, note-length and end-only operations, Bypass, Fix overlaps, swing-grid intersection, and remembered dialog settings are not exposed or implemented. The native strength slider and default were captured, but native 50% quantization output has not been measured; AAADAW's strength path is covered by app regression only. These gaps remain in progress in the parity matrix.

The rebuilt Linux AAADAW desktop was exercised under isolated Xvfb at 1280×800; Build ID, binary hash, screenshots, and fixture hashes are recorded in the [dialog fixture manifest](fixtures/midi-quantize-dialog-ui.tsv). Workspace Nextest passed **1411 tests across 74 binaries** under Xvfb. Strict workspace all-target Clippy (`-D warnings`), formatting, diff checks, the 106-row/15-column unique-ID parity matrix check, and all dialog fixture hashes passed.
