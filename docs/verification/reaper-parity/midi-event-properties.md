# MIDI Event Properties

Linux REAPER 7.82 / Default 7 uses MIDI Editor action 40004, `Edit: Event properties`, in MIDI Event List section 32061, with `Ctrl+F2`. With one Note selected, the native window exposes Type, BBT Position, BBT Length, Channel, Note, Velocity, Off value, and OK/Cancel/Apply. A disposable-profile ReaScript creates a selected note at tick 720 with length 240, channel 3, pitch 60, and velocity 91, then opens the Event List and action 40004. REAPER displays `1.1.75`, `0.0.25`, `3`, `60 C4`, `91`, and off value `0`.

The native CC probe selects controller 7 at tick 480, channel 3, value 90. REAPER displays Position `1.1.50`, Channel `3`, Controller `07 Volume MSB`, Value `90`, CC shape `Square`, Bezier tension `0.00`, and OK/Cancel/Apply. The probe script, readback, and cropped native screenshot are listed alongside the Note evidence in the [fixture manifest](fixtures/midi-event-properties-ui.tsv).

The native Pitch Bend probe selects raw value `9000` at tick 480, channel 3. REAPER displays Type `Pitch`, Position `1.1.50`, Channel `3`, Value `9000` with the centered offset `(+808)`, CC shape `Square`, Bezier tension `0.00`, and OK/Cancel/Apply. The isolated-profile probe and cropped screenshot are in the same manifest.

AAADAW registers `Edit: Event properties` with the native Ctrl+F2 shortcut and opens it from the Event List for exactly one selected Note, CC, or Pitch Bend. Notes accept absolute `bar.beat.hundredths` Position/Length, Channel 1–16, MIDI pitch numbers or names such as `C♯4`, and Velocity 0–127. CC events accept Position, Channel 1–16, a named controller selector, and Value 0–127. Pitch Bend accepts Position, Channel 1–16, and raw Value 0–16383; the dialog also displays the offset from center value 8192. Apply commits one undoable event update and refreshes the dialog, OK commits and closes, and Cancel/Escape discard draft values. Invalid BBT and model values leave the draft open with feedback. The [Note desktop capture](fixtures/midi-event-properties-aaadaw.png), [CC desktop capture](fixtures/midi-event-properties-cc-aaadaw.png), and [Pitch Bend desktop capture](fixtures/midi-event-properties-pitch-bend-aaadaw.png) are real AAADAW Xvfb window screenshots. Separate CC and Pitch Bend captures document the applied values and Undo/Redo results.

This does not complete native Event Properties parity. Multiple selected events, direct keyboard-relative `+`, `-`, `*`, `/` values, the `+1o` octave syntax, and persistent note-off velocity are not implemented. The project model currently stores no note-off velocity, CC shape, or Bezier tension, so the dialogs disclose those omissions. Event Properties BBT editing uses the project PPQ and meter at tick zero; meter-map changes, source offsets, and loop-source occurrences still need native probes. `MIDI-EVENT-PROPERTIES-001`, `MIDI-EVENT-LIST-001`, UI-019, and P7 remain `in_progress`.
