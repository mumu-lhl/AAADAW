# Signed negative MIDI source offsets in Item Contents Nudge

Linux REAPER `7.82/linux-x86_64` with `Default_7.0.ReaperThemeZip` was run in an isolated Xvfb session. The probe creates a selected, non-looped five-second MIDI item at 2 seconds with a ten-quarter-note source, `D_STARTOFFS=-0.1` seconds (-192 PPQ at the fixture's constant 120 BPM), and notes at PPQ 2880 and 6720. Main action 41226 opens Item Nudge/Set; the real dialog was configured to Nudge → Contents → 250 milliseconds with Snap off. The [native screenshot](fixtures/item-nudge-midi-negative-source-offset-native.png) records that dialog and project before the first nudge.

From a fresh negative-offset state, Nudge left changes the source offset to +0.15 seconds (+288 PPQ) and leaves source length and note events unchanged. In a separate fresh run, Nudge right stores +1 PPQ (+0.000520833 seconds), extends the source to 10.701041667 quarter notes, and shifts both notes forward by 673 PPQ. The [separate right-from-initial readback](fixtures/item-nudge-midi-negative-source-offset-right-native.tsv) preserves the independent run. The [left-then-right readback](fixtures/item-nudge-midi-negative-source-offset-native.tsv) also records the sequential case: after left, right ends at +1 PPQ with a 193-PPQ event shift and a 10.201041667-quarter-note source. Each row keeps item bounds and selection unchanged.

AAADAW's non-loop Contents Nudge now uses the signed source-offset mapping. The regression `item_nudge_non_looped_midi_contents_preserves_native_negative_offset_boundaries` checks the independent right and left results, including source extent, event positions, and Undo; `item_nudge_moving_a_non_loop_midi_item_preserves_its_signed_source_offset` checks that moving the whole item retains its negative source offset and Undo/Redo. The real REAPER capture can be reproduced with [the probe](../../../scripts/reaper_parity/probe-item-nudge-midi-nonloop.lua) and [capture script](../../../scripts/reaper_parity/capture-item-nudge-midi-signed-native.sh); use the second argument `right` for a fresh right-only state, or the default `left-right` for the sequential fixture.

One boundary remains open: the sequential native Left → Right result uses +1 PPQ and shifts events by 193 PPQ, while the current AAADAW path represents the same intermediate +288-PPQ offset by clamping the second nudge at zero. The independent negative-offset left and right cases are covered; exact chained-boundary parity needs a richer model of REAPER's source rebasing. This fixture uses constant 120 BPM and does not establish general tempo-map behavior or broad Nudge Undo-history parity.
