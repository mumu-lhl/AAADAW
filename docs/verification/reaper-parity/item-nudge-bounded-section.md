# Contents Nudge on a disabled bounded source section

Linux REAPER `7.82/linux-x86_64` / `Default_7.0.ReaperThemeZip` was run with a fresh profile and an unsaved, stopped project. A deterministic 10-second, 48 kHz mono WAV was inserted. Main action `40014` copied a three-second time selection, action `42398` pasted the bounded source section at 12 seconds, and the pasted item was set to length 3 seconds with `B_LOOPSRC=0` and `D_STARTOFFS=0.1` seconds.

The Nudge/Set Items window was opened with action `41226`; its actual controls were set to Mode `Nudge`, Target `contents`, amount `250` milliseconds, and Snap off. Main action `41249` (`Item edit: Nudge right by last nudge dialog settings`) changed `D_STARTOFFS` to `-0.15` seconds. Both the `[0, 3]` and nonzero `[3, 6]` source-section cases retained their section length, loop-off flag, item position 12 seconds, and item length 3 seconds. The REAPER project state-change count delta was zero. Exact ReaScript reads are in [the native TSV](fixtures/item-nudge-bounded-section-native.tsv); the live dialog after the nonzero-section case is [captured here](fixtures/item-nudge-bounded-section-native-dialog.png), SHA-256 `241586412f38e8643aa18667086fc52d23974962c0f865a5db3d06d92a4b10fd`.

This confirms that bounded-section `D_STARTOFFS` is relative to the section view, while the section start separately addresses the original media file. It also confirms that a disabled bounded section accepts negative Contents Nudge and retains its one-pass bounds. AAADAW stores the section origin and signed section-relative offset separately; its feeder emits pre-roll silence before decoding from the section start and stops at the section end. Core, Media, Storage, Nudge, and waveform regressions cover those contracts.

This probe verifies REAPER's item state after the nudge action. It does not claim a sample-by-sample audible comparison of REAPER's output for negative offsets, nor does it complete all Nudge/Set targets, Snap modes, selection anchors, or dialog visual parity. `ITEM-NUDGE-SET-001` remains in progress.
