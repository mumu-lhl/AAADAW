# Absolute Set → Contents for a mixed Audio/MIDI selection

Linux REAPER `7.82/linux-x86_64` with `Default_7.0.ReaperThemeZip` was tested in a fresh, unsaved project with transport stopped. The selected Audio item and MIDI item both started at 2 seconds, lasted 5 seconds, and used Loop source. The Audio item used the bundled four-second WAV at source offset 0.1 seconds. The MIDI item used a ten-quarter-note (9,600 PPQ at 120 BPM) loop with two notes at source PPQ 0–960 and 4,800–5,760.

In the real Nudge/Set window, Mode was `Set`, Target was `contents`, the absolute target was 3 seconds, and Snap was off. One Apply operation changed Audio `D_STARTOFFS` to 3 seconds and MIDI `D_STARTOFFS` to 4 seconds (7,680 PPQ phase in the 9,600 PPQ loop). Both item positions and five-second lengths remained unchanged; both items stayed selected and both MIDI notes remained present. The [native TSV](fixtures/item-nudge-mixed-set-contents-native.tsv) records all before/after/undo/redo values and project state counters. The [probe script](../../../scripts/reaper_parity/probe-item-nudge-mixed-set-contents.lua) constructs the fixture and captures those snapshots.

One native Undo restored both source offsets to 0.1 seconds and 0 seconds; one Redo restored 3 seconds and 4 seconds. The next Undo label after the Set had been undone was `Remove loop/time selection`; the observed Set/Undo/Redo values are the evidence here, without inferring any deeper history behavior.

AAADAW computes the selected Audio and loop-source MIDI placements before applying either, then commits both action lists in one `BatchTransaction`. Its mixed-selection regression verifies one revision change, unchanged bounds, offsets for each media type, and one-step Undo/Redo. A second regression verifies that missing Audio source metadata prevents the MIDI edit from partially applying. The native probe now confirms that REAPER also changes both media types together for this Set operation.

The configured native dialog, applied result, Undo, and Redo are actual REAPER window captures: [dialog](fixtures/item-nudge-mixed-set-contents-native-dialog.png), [after](fixtures/item-nudge-mixed-set-contents-native-after.png), [Undo](fixtures/item-nudge-mixed-set-contents-native-undo.png), and [Redo](fixtures/item-nudge-mixed-set-contents-native-redo.png). This mixed Set probe covers one full-file Audio source and one looped MIDI source at constant 120 BPM; bounded Audio sections, non-loop MIDI, other snap units, other targets, and broader Undo history remain open. `ITEM-NUDGE-SET-001` stays `in_progress`.
