# MIDI Event Filter: Set Filter from Selection

Reference: Linux REAPER 7.82, Default 7 theme. The native probe starts with three selected Notes on channels 2–4, one unselected Note on channel 5, and an existing Note/channel-5 filter.

Clicking `Set filter from selection` replaces the channel mask with channels 2–4 and populates Note, Velocity, Position in measure, and Length criteria from the selected Notes. The measured ranges are pitch C4–G4, velocity 91–93, measure position 0–0.25026042, and length 1/16–1/16. The MIDI Editor channel changes to Multichannel and Draw events on channel resets to Channel 1. Show-only, Invert, and Solo remain off, and Repeat every remains unchecked. The event data and the three selected Notes remain unchanged. Native screenshots and before/after RPP readbacks are listed in the [fixture manifest](fixtures/midi-event-filter-from-selection-native.tsv).

The native probe covers homogeneous Note selection. A separate CC probe selects CC7 value 64 on channel 2 at tick 480 and CC7 value 100 on channel 3 at tick 960, with an unselected CC10 and CC7 value 127 as controls. `Set filter from selection` sets the channel mask to channels 2–3, Event type to Control Change, Control to `07 Volume MSB`, Value to 64–100, and Position in measure to 1/8–0.25026042; Repeat every is `measure`. The MIDI Editor channel becomes Multichannel and Draw events on channel stays Channel 1. Show-only, Invert, and Solo remain off. The selected CCs and MIDI source data remain unchanged. The [CC fixture manifest](fixtures/midi-event-filter-from-cc-native.tsv) records the selected-bit readback, both RPP states, and screenshots.

AAADAW derives channel, event type, controller, inclusive Value, and Position criteria from homogeneous selected CCs; it preserves the selected CCs, Show-only/Invert/Solo state, and project data, and resets Draw events on channel to Channel 1. The [current-build fixture manifest](fixtures/midi-event-filter-from-cc-aaadaw.tsv) records its real-window capture and regression. The existing [Note-selection captures](fixtures/midi-event-filter-from-selection-aaadaw.tsv) continue to verify pitch, velocity, Position, and note Length derivation. Mixed event types, multiple CC parameters, selected Pitch Bend, Program Change, Poly Aftertouch, Channel Pressure, Meta, and SysEx remain open, so Event List acceptance remains `in_progress`.
