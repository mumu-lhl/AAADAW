# MIDI Event Filter: Set Filter from Selection

Reference: Linux REAPER 7.82, Default 7 theme. The native probe starts with three selected Notes on channels 2–4, one unselected Note on channel 5, and an existing Note/channel-5 filter.

Clicking `Set filter from selection` replaces the channel mask with channels 2–4 and populates Note, Velocity, Position in measure, and Length criteria from the selected Notes. The measured ranges are pitch C4–G4, velocity 91–93, measure position 0–0.25026042, and length 1/16–1/16. The MIDI Editor channel changes to Multichannel and Draw events on channel resets to Channel 1. The native Event List probe began with its funnel on; `Set filter from selection` turned it off, leaving all rows visible. Show-only, Invert, and Solo remain off, and Repeat every remains unchecked. The event data and the three selected Notes remain unchanged. Native screenshots and before/after RPP readbacks are listed in the [fixture manifest](fixtures/midi-event-filter-from-selection-native.tsv).

The native probe covers homogeneous Note selection. A separate CC probe selects CC7 value 64 on channel 2 at tick 480 and CC7 value 100 on channel 3 at tick 960, with an unselected CC10 and CC7 value 127 as controls. `Set filter from selection` sets the channel mask to channels 2–3, Event type to Control Change, Control to `07 Volume MSB`, Value to 64–100, and Position in measure to 1/8–0.25026042; Repeat every is `measure`. The MIDI Editor channel becomes Multichannel and Draw events on channel stays Channel 1. Show-only, Invert, and Solo remain off. The [CC fixture manifest](fixtures/midi-event-filter-from-cc-native.tsv) records the selected-bit readback, RPP state, and dialog screenshot; its Event List funnel state was not captured independently.

AAADAW derives channel, event type, controller, inclusive Value, and Position criteria from homogeneous selected CCs; it preserves the selected CCs, Show-only/Invert/Solo state, and project data, and resets Draw events on channel to Channel 1. The [homogeneous CC fixture manifest](fixtures/midi-event-filter-from-cc-aaadaw.tsv) records a real-window capture and regression. The existing [Note-selection captures](fixtures/midi-event-filter-from-selection-aaadaw.tsv) verify pitch, velocity, Position, and note Length derivation. A mixed-parameter CC selection disables Control and displays `<all>`, while deriving the selected events' inclusive Value and Position ranges. The [current-build mixed-parameter fixture manifest](fixtures/midi-event-filter-from-mixed-cc-aaadaw.tsv) records that behavior.

A mixed-parameter probe selects CC7 value 64 on channel 2 at tick 480 and CC10 value 100 on channel 3 at tick 960. REAPER disables Control and displays `<all>`, while retaining Value 64–100 and Position 0.125–0.25026042. The probe explicitly turns on the Event List funnel after deriving the criteria; with the funnel on, four rows pass channel, type, Value, and Position, including unselected CC1 and CC10 events, while Show-only remains unchecked. The before/after RPPs and [mixed-parameter fixture manifest](fixtures/midi-event-filter-from-mixed-cc-native.tsv) confirm MIDI source data and event selection bits are unchanged.

AAADAW supports both homogeneous and mixed-parameter CC selections. It disables Control for the latter and keeps the inclusive Value and Position ranges. `Set filter from selection` leaves the Event List funnel off; explicitly enabling it shows the four matching rows with the two selected rows preserved. Enabling Show-only also activates the Event List filter; turning the Event List filter off resets Show-only. The [mixed-parameter AAADAW manifest](fixtures/midi-event-filter-from-mixed-cc-aaadaw.tsv) records the current behavior. The [native toggle manifest](fixtures/midi-event-filter-toggle-native.tsv) captures the Show-only/funnel relationship and confirms that disabling the funnel clears Show-only.

A native Pitch Bend selection probe selects raw values 4096 on channel 2 and 12288 on channel 3, with an unselected raw value 10000 between them. REAPER displays signed values −4096…+4096, Position 1/8–0.25026042, and the matching channel mask; Repeat every is disabled for Pitch. The funnel remains off after setting the criteria and all six rows remain visible until it is explicitly enabled. With the funnel on, exactly the three matching Pitch Bend rows appear, including the unselected +1808 event. The [Pitch Bend manifest](fixtures/midi-event-filter-from-pitch-native.tsv) includes native screenshots, project readbacks, and the setup script.

AAADAW now derives selected Pitch Bend channel, signed value, and Position ranges, and applies those criteria to the Event List only when its funnel is enabled. The [Pitch Bend app tests](../../../crates/aaadaw/src/app/tests.rs) cover range derivation, filtering, selected-event retention, and unchanged project/undo state.

Native readbacks and screenshots are recorded in the [Program Change native manifest](fixtures/midi-event-filter-from-program-native.tsv).

A native mixed Note+CC probe selects C4 on channel 2 at tick 480 and CC7 value 100 on channel 3 at tick 960. REAPER sets Event type to `<all events>`, channels 2–3, and Position 0.125–0.25026042; Repeat remains measure, Draw events on channel is 2, and Note/Velocity/Parameter/Value/Length criteria stay disabled. Set turns Show-only off. With Show-only enabled, five rows pass: three matching CCs, the selected Note, and a channel-less Text Meta inside the Position range. An out-of-range SysEx and the unselected G4 are hidden. The selected Note and CC remain selected and the 139-byte `MIDI_GetAllEvts` source is byte-identical before and after.
