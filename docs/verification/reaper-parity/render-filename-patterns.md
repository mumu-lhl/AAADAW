# Render filename wildcard patterns

Linux REAPER 7.82 / Default 7 places a `File name` pattern field and `Wildcards` button in the Render window. The captured selected-item case uses `$region-$item` and resolves to `bounds-ui-Region 2-item_02.wav`; the reference dialog and measured output are archived in [the native screenshot](images/render-selected-items-native.png) and [the output record](render-selected-items-native.tsv). The native Region Render Matrix fixture uses `$region-$track` and emits `Intro-Master.wav`, `Intro-Drums.wav`, `Intro-Guitar.wav`, and `Verse-Bass.wav`.

AAADAW now provides an optional filename-pattern field in its Render window and a grouped `Wildcards…` picker immediately below it. Its 40 implemented tokens cover `$project`, `$title`, `$author`, `$projectnotes`, `$bpm`, `$tempo`, `$timesignature`, `$timesignum`, `$timesigdenom`, `$track`, `$tracknumber`, `$tracknameornumber`, `$region`, `$regionnumber`, `$marker`, `$markernumber`, `$item`, the 18 Position/Length tokens `$start`, `$end`, `$length`, `$startbeats`, `$endbeats`, `$lengthbeats`, `$starttc`, `$endtc`, `$startframes`, `$endframes`, `$lengthframes`, `$startseconds`, `$endseconds`, `$lengthseconds`, `$lenhh`, `$lenmm`, `$lenss`, and `$lentt`, plus `$format`, `$samplerate`, `$sampleratek`, `$bitdepth`, and `$channels`. Project metadata values come from the existing Project Notes model. Selecting a token appends it to the end of the pattern and closes the picker. A chosen output path supplies the directory and extension; a blank pattern retains the existing generated names. The resolver sanitizes characters unsafe in file names and rejects patterns that resolve multiple jobs to the same name before queueing. The Render job still publishes through the existing atomic batch writer.

Wildcard text expansion now follows the native help for capitalization (`$Track`, `$TRACK`, `$tRACK`), `<X>` removal, `<abcdeX>` replacement, and `[<N]` prefix truncation. When a known wildcard expands to an empty string, one adjacent space, hyphen, underscore, or dot is omitted, following the native help rule. Unit regressions cover those transformations; native help captures are linked in the [catalog](render-wildcard-catalog.md).

The regression resolves the native `$region-$track` matrix pattern to the same four native target names, renders those jobs through AAADAW's offline audio renderer, and compares every PCM24 sample to the matching REAPER output. A second test resolves `$region-$item` to the observed `Intro-item_01.wav` form. The context-expansion regression checks Project Notes title/author/text, all Position/Length values, and track, region, tempo, and time-signature values; an unnamed track resolves `$tracknameornumber` to the native `Track 02` form. The native unnamed-track render preview shows `Track 01.wav`. Separate cases cover safe-name conversion, blank-pattern fallback, unknown literal tokens, and duplicate-name rejection. The queue test sets `$project-$track` through the Render message and checks that queued stem paths use the expanded project and track names; it also verifies duplicate names leave the queue unchanged. The picker regression covers all 40 visible tokens, appending the selected token, and closing the menu. The output-context regression checks native values for WAV format, 44.1/22.05 kHz formatting, 16/24/32/64-bit PCM/float and 4/2-bit compressed WAV values, and Mono/Stereo channel counts. See the manifest for current build, screenshot hashes, and validation counts.

The [native wildcard catalog](render-wildcard-catalog.md) records the 97 entries visible in REAPER 7.82 menus and the native Wildcard help rules. This does not complete REAPER Wildcards parity: AAADAW exposes 40 tokens in a flat scrollable grouped picker and appends at the pattern end; insertion at the caret or over a selection, `$projectnotes(name)` and named-note parsing, project directory variants, region/marker/item note and name expressions, folders/parent/FX, recording names, date/time/unique IDs, computer/user values, REAPER's full ordering and escaping rules, pattern presets and cross-launch persistence, native collision prompts, non-WAV formats, per-channel `$chid`, and remaining source/range combinations are open. Position/Length formatting is verified with the default 4/4 meter and 30 fps, while project time offset, meter changes across the render range, other frame rates, drop-frame modes, and Tail interactions still need native comparisons. The native context captures verify track number/name, region number, tempo, time signature components, marker number, project title/author/notes, and the sampled time/beat/frame output forms. `$marker` text/name expansion and many source-dependent values still need native comparisons. `RENDER-WILDCARDS-001`, `RENDER-SOURCE-001`, and `UI-028` remain `in_progress`.
