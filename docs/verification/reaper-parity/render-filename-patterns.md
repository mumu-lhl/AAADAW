# Render filename wildcard patterns

Linux REAPER 7.82 / Default 7 places a `File name` pattern field and `Wildcards` button in the Render window. The captured selected-item case uses `$region-$item` and resolves to `bounds-ui-Region 2-item_02.wav`; the reference dialog and measured output are archived in [the native screenshot](images/render-selected-items-native.png) and [the output record](render-selected-items-native.tsv). The native Region Render Matrix fixture uses `$region-$track` and emits `Intro-Master.wav`, `Intro-Drums.wav`, `Intro-Guitar.wav`, and `Verse-Bass.wav`.

AAADAW now provides an optional filename-pattern field in its Render window and a grouped `Wildcards…` picker immediately below it. Its 14 implemented tokens are `$project`, `$bpm`, `$tempo`, `$timesignature`, `$timesignum`, `$timesigdenom`, `$track`, `$tracknumber`, `$tracknameornumber`, `$region`, `$regionnumber`, `$marker`, `$markernumber`, and `$item`. Selecting one appends it to the end of the pattern and closes the picker. A chosen output path supplies the directory and extension; a blank pattern retains the existing generated names. The resolver sanitizes characters unsafe in file names and rejects patterns that resolve multiple jobs to the same name before queueing. The Render job still publishes through the existing atomic batch writer.

The [AAADAW filename-field capture](fixtures/render-filename-pattern-aaadaw.png), [expanded picker capture](fixtures/render-filename-pattern-wildcards-aaadaw.png), and [track-token insertion capture](fixtures/render-filename-pattern-wildcard-insert-aaadaw.png) were taken from the rebuilt desktop binary. The reproducible [capture script](../../../scripts/reaper_parity/capture-render-filename-pattern-aaadaw.sh) drives the visible Render command with Ctrl+Alt+R; set `AAADAW_OPEN_WILDCARDS=1` to capture the expanded picker, or `AAADAW_INSERT_WILDCARD=tracknumber` to click the visible token and capture the resulting field. Native UI probes accept `AAADAW_REAPER_WILDCARD_PATTERN` to replace their default `$region-$item` or `$marker-$item` pattern. Two additional native captures verify expansion in context: `$tracknumber-$tracknameornumber-$regionnumber-$tempo-$timesignature-$timesignum-$timesigdenom` produces `01-Render fixture-02-120-4-4-4-4.wav` for the selected item, and `$markernumber` produces `01.wav` for the first marker. See the [native context capture](fixtures/render-wildcards-context-native.png) and [native marker capture](fixtures/render-wildcards-marker-native.png). Screenshot hashes, native inputs, implementation tokens, and regression results are in the [fixture manifest](fixtures/render-filename-pattern-aaadaw.tsv).

The regression resolves the native `$region-$track` matrix pattern to the same four native target names, renders those jobs through AAADAW's offline audio renderer, and compares every PCM24 sample to the matching REAPER output. A second test resolves `$region-$item` to the observed `Intro-item_01.wav` form. The context-expansion regression checks the added track, region, tempo, and time-signature variables; separate cases cover `$project`, `$marker`, `$item`, `$bpm`, safe-name conversion, blank-pattern fallback, unknown literal tokens, and duplicate-name rejection. The queue test sets `$project-$track` through the Render message and checks that queued stem paths use the expanded project and track names; it also verifies duplicate names leave the queue unchanged. The picker regression covers all 14 visible tokens, appending the selected token, and closing the menu. See the manifest for current build, screenshot hashes, and validation counts.

This does not complete REAPER Wildcards parity. The picker exposes a tested subset of the native token set and appends at the pattern end; insertion at the caret or over a selection, project/region/marker/item notes and name expressions, folders/parent/FX, positions and timecode, recording names, output format/channels, date/time/unique IDs, computer/user values, REAPER's full ordering and escaping rules, pattern presets and cross-launch persistence, native collision prompts, and remaining source/range combinations are open. The native context captures directly verify track number/name, region number, tempo, time signature components, and marker number. `$marker` text/name expansion and many source-dependent values still need native comparisons. `RENDER-WILDCARDS-001`, `RENDER-SOURCE-001`, and `UI-028` remain `in_progress`.
