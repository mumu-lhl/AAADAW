# Set → Contents for bounded audio sections

Linux REAPER `7.82/linux-x86_64` with the Default 7 theme was captured in an isolated Xvfb session. The probe copies a bounded loop section from 1 to 4 seconds, places the resulting selected item at 2 seconds with a five-second length, enables Loop source, and sets its source offset to 0.1 seconds. The Nudge/Set dialog was configured to Set → Contents → `0:03.000`, Snap off.

The native Set changes `D_STARTOFFS` from 0.1 to 2.0 seconds while preserving the copied section `[1, 4]` seconds, item position/length, loop flag, and selection. Undo restores 0.1 seconds and Redo restores 2.0 seconds. The [native TSV](fixtures/item-nudge-bounded-audio-set-contents-native.tsv) records all four states and REAPER's state-change/undo labels. The [configured dialog](fixtures/item-nudge-bounded-audio-set-contents-native-dialog.png), [applied state](fixtures/item-nudge-bounded-audio-set-contents-native-after.png), [Undo](fixtures/item-nudge-bounded-audio-set-contents-native-undo.png), and [Redo](fixtures/item-nudge-bounded-audio-set-contents-native-redo.png) are real REAPER captures. The after and Redo frames are pixel-identical because both show the same project state.

AAADAW already maps the absolute project-time target into the bounded section's source interval. The expanded regression `item_nudge_set_contents_aligns_audio_loop_and_signed_source_offsets` uses a 96 kHz source section `[96,000, 384,000)` in a 48 kHz project, sets the same 2-to-3-second case, and checks the resulting 192,000-frame offset, unchanged section and item bounds, selected item, and one-step Undo/Redo. This covers source-rate conversion in addition to the 48 kHz native fixture.

The [reproducible REAPER probe](../../../scripts/reaper_parity/probe-item-nudge-bounded-audio-set-contents.lua) creates the source section and opens action 41226. Set mode, Contents target, `0:03.000`, and Snap off are configured in the native dialog; after clicking Apply move, send `snapshot`, `undo`, and `redo` on separate lines to `item-nudge-bounded-audio-set-contents-command.txt` in the probe directory. Run `done` to close the TSV. The fixture uses a constant tempo and one section; other section ranges, Snap units, mixed selections, and broader Undo-history parity remain open. `ITEM-NUDGE-SET-001` remains `in_progress`.
