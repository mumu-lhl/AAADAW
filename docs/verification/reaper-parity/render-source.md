# Linux REAPER 7.82 Render source modes

The official [REAPER 7.81 User Guide, section 21.5](https://www.reaper.fm/userguide/ReaperUserGuide781c.pdf) describes Selected tracks via master as rendering each selected track through its folder and send paths, then through Master processing, without including unrelated media from those paths. The official [ReaScript GetSetProjectInfo reference](https://www.reaper.fm/sdk/reascript/reascripthelp.html#GetSetProjectInfo) assigns `RENDER_SETTINGS=128` to Selected tracks via master; `RENDER_SETTINGS=0` is Master mix. The installed REAPER 7.82 API reference contains the same values.

The [probe script](../../../scripts/reaper_parity/probe-render-source.lua) ran in a fresh isolated 7.82 configuration and Default 7 theme. It set up two identical, centered tracks from one 48 kHz PCM24 source, selected one, and requested Master mix (`RENDER_SETTINGS=0`) and Selected tracks via master (`RENDER_SETTINGS=128`). Both files were 48 kHz, PCM24 stereo and 48,000 frames. The Master mix's stable sample was `[0.25, 0.75]`; the selected-track file's was `[0.125, 0.375]`. The selected-track output was named `selected-via-master-Selected.wav`, confirming the `$track` wildcard for this one-track case. The run log read back flags 0 and 128. This probe does not cover folder/send routing, multi-track file counts, or FX behavior.

AAADAW currently adds a Selected track via master source choice. It requires exactly one Arrange track selection, freezes that `TrackId` into the queued job, creates an isolated in-memory project snapshot with only that track soloed, and uses the existing offline Master graph. The saved project, its solo state, live playback, and selected-track UI state are not mutated. An integration regression renders two identical sources and verifies the selected-track output has half the level of the full Master mix, while the original project remains unsoloed.

This is a single-selected-track subcase. Rendering multiple selected tracks to separate files, native wildcard naming, Master plus stems, pre-fader stems, plain stem modes, region matrix, items, Razor edits, multichannel routing, and full native output comparison remain incomplete. `RENDER-SOURCE-001` and `UI-028` stay `in_progress`.
