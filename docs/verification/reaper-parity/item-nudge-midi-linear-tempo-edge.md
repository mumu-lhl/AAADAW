# Non-loop MIDI edge Nudge across a linear tempo ramp

Linux REAPER 7.82 / Default 7 was tested with a 120-to-60 BPM Linear ramp ending at measure 3 (5.333333 seconds), a non-loop Audio item at 2 seconds, and a non-loop MIDI item spanning 3.900–8.900 seconds. The MIDI source starts at PPQ zero and contains notes at 960 and 2,880 PPQ, a CC at 4,800 PPQ, and a pitch bend at 5,760 PPQ. In the actual `Nudge/Set Items` dialog, Mode was `Nudge`, Target was `left trim`, the amount was 250 milliseconds, and Snap was off.

After Nudge right, REAPER placed the Audio item at 2.250 seconds, shortened it to 9.750 seconds, and set its source offset to 0.250 seconds. The MIDI item moved from 3.900 to 4.150 seconds and shortened from 5.000 to 4.750 seconds. REAPER shifted source events by 298 PPQ (notes 960/2,880 → 662/2,582; CC 4,800 → 4,502; pitch bend 5,760 → 5,462), and shortened the native source from 6.000 to 5.689583333 quarter notes (5,462 PPQ). Its take offset retained a sub-tick remainder: `D_STARTOFFS=0.000745908` seconds and `MIDI_GetPPQPosFromProjTime` returned 0.875 PPQ at the new item edge. A second Nudge left restored the original item bounds, source length, offset, and event positions. The project state count advanced from 2 to 3 for the first action; the native undo label was `Nudge items`.

This probe exposed a base time-map mismatch: AAADAW had interpolated Linear BPM over PPQ, while REAPER interpolates BPM over project time. `TempoCurve::Linear` now uses the REAPER time-based mapping for both tick-to-sample and sample-to-tick conversions. A 120-to-60 BPM ramp over 7,680 PPQ now spans exactly 256,000 samples at 48 kHz. The non-loop edge Nudge converts the precise project-time delta to integer source-event movement by truncating toward zero, matching REAPER's 298-PPQ event shift for this 298.875-PPQ interval. The App regression verifies item bounds, source length, notes, CC, pitch bend, selection, and one-step Undo/Redo.

The model still stores MIDI take source offsets and source-loop lengths as integer PPQ. It therefore cannot retain REAPER's 0.875-PPQ edge phase / `D_STARTOFFS` remainder exactly; the AAADAW regression keeps source offset zero while event PPQ and source length match the native values. The native pitch bend at 5,760 PPQ lies beyond the model's visible non-loop item extent, so the App regression uses a pitch bend at 4,500 PPQ to exercise source-data shifting within the currently representable visible range. Exact sub-tick MIDI source phase and hidden source-tail event editing remain open.
