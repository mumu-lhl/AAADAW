# Absolute Set → Contents for looped MIDI

Linux REAPER `7.82/linux-x86_64` with `Default_7.0.ReaperThemeZip` was opened in a fresh, unsaved project with transport stopped. The probe created one selected looped MIDI item at 2 seconds with a 5-second item length, a 9,600-PPQ source loop, and two source notes. In the real Nudge/Set dialog, Mode was `Set`, Target was `contents`, the absolute target was 3 seconds, and Snap was off. Relative Set was not shown for this target.

Applying the target kept the item at 2 seconds with its 5-second length and selection intact. `D_STARTOFFS` became 4 seconds, the source phase was 7,680 PPQ, and the loop endpoint was 17,280 PPQ, preserving the 9,600-PPQ loop. The observed wrap is `(item start − target) mod source-loop duration`: `(2 − 3) mod 5 = 4` seconds. The native dialog screenshots capture the initial 2-second source alignment and the resulting wrapped source start; the post-action dialog displays `-0:01.999` in its source-start summary. Raw state samples are preserved in the [native TSV](fixtures/item-nudge-midi-set-contents-native.tsv), and the [ReaScript probe](../../../scripts/reaper_parity/probe-item-nudge-midi-set-contents.lua) records the project and item state.

With Snap to unit enabled, a second run used an absolute target of 3.500 seconds. REAPER rounded that target to 4 seconds and set `D_STARTOFFS` to 3 seconds (5,760 PPQ phase, 15,360 PPQ loop endpoint); the item remained at 2–7 seconds and selected. The before/after values are in the [Snap-on fixture](fixtures/item-nudge-midi-set-contents-snap-native.tsv), and the [Snap-on window capture](fixtures/item-nudge-midi-set-contents-native-snap-on.png) shows the enabled checkbox and resulting source start. This establishes nearest-second snapping for the tested `minutes:seconds` unit at 120 BPM, including the 3.5-second tie case.

AAADAW implements this absolute Set path for selected loop-source MIDI items. It converts item and target project positions through the Tempo Map, wraps the resulting source offset inside the MIDI source loop, and applies all selected MIDI placements in one project transaction. The app regression verifies both the native Snap-off 2-second item / 3-second target (phase 7,680 PPQ) and nearest-second Snap-on case (target 3.500 → 4.000 seconds, phase 5,760 PPQ), unchanged item bounds and selection, and one-step Undo/Redo.

The latest desktop binary was also run with a selected 2-second looped MIDI item starting at 1 second and a C4 event at source tick 0. Through the actual Set/Contents dialog I applied target 3.500 seconds with Snap on. Its recovered project snapshot shows item start tick 1,920, length and source loop 3,840 ticks, source offset 1,920 ticks, and the note still at tick 0; the note preview appears 1 second into the item. The [runtime state fixture](fixtures/item-nudge-midi-set-contents-aaadaw-run.tsv) and [post-apply window capture](fixtures/item-nudge-midi-set-contents-aaadaw-applied.png) record the interaction from the same latest build. Changing the target to Contents clears Relative Set; the configured dialog capture shows that the checkbox is absent for this target.
