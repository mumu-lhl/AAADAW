# Item Length, Item Selection, and Note Nudge Units

This record compares the remaining REAPER 7.82 / Default 7 Nudge units against AAADAW's Position Nudge implementation. The native probe ran at 44.1 kHz, 120 BPM, with Snap off. It used Audio A at 1.000 s / 0.500 s, Audio B at 4.000 s / 1.000 s, a MIDI item from 0 to 8 seconds with three notes, and a 2–5 second time selection. The [ReaScript](../../../scripts/reaper_parity/probe-item-nudge-relative-units.lua) captures native item and note state; the normalized [fixture TSV](fixtures/item-nudge-relative-units-native.tsv) records every before/after state.

REAPER's `item lengths` unit uses the first selected item's duration as the shared movement. Audio A alone moves 0.500 s, Audio B alone moves 1.000 s, and selecting both moves each by 0.500 s. The selected items do not each use their own duration. The actual [single-item result](fixtures/item-nudge-item-lengths-native-after.png) shows Audio A at 1.500 s.

`item selections` uses the envelope from the earliest selected start to the furthest selected end. Audio A alone gives 0.500 s, Audio B gives 1.000 s, and selecting both spans 1.000–5.000 s for a 4.000 s step. The time selection does not supply this step: it remains 2–5 s in the probe and differs from the measured four-second item-selection span. A selected 0–8 s MIDI item gives an eight-second step. The actual [multi-item result](fixtures/item-nudge-item-selections-native-after.png) shows both Audio items advanced by four seconds.

`notes` is a musical note-value unit, independent of the selected media type or MIDI note lengths. Its second dropdown offers `1/256`, `1/128`, `1/64`, `1/32T`, `1/32`, `1/16T`, `1/16`, `1/8T`, `1/8`, `1/4T`, `1/4`, `1/2`, and `whole`; the [native dropdown capture](fixtures/item-nudge-notes-values-native-menu.png) shows the full list. At 120 BPM, one `1/4` moves a selected MIDI item and a selected Audio item by 0.500 s, while `1/2` moves the Audio item by 1.000 s. The [MIDI result](fixtures/item-nudge-notes-quarter-native-after.png) shows the selected MIDI item at 0.500 s. The MIDI item’s first note is only 0.250 s long, so this result confirms that REAPER uses the selected musical value rather than inspecting note contents.

AAADAW now offers all three native Nudge units in REAPER's menu order. Item lengths and item selections calculate one shared delta from the earliest selected item and apply it to the entire selection. Notes exposes the native 13-value selector and maps the selected musical duration through the project tempo map. Each operation remains one undoable project edit. Focused App regressions cover unequal Audio lengths, mixed Audio/MIDI selection movement, selection-envelope duration, quarter and quarter-triplet notes, a tempo change at the selected position, and Undo/Redo.

This comparison establishes Position Nudge with Snap off at a constant tempo. Native Snap behavior for these three units, other Nudge targets, variable meter and tempo probes for the `notes` unit, and broader Undo counter parity remain open. `ITEM-NUDGE-SET-001` and P4 stay `in_progress`; this slice does not claim full REAPER parity.
