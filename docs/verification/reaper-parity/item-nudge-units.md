# Item Nudge units and Snap

This REAPER 7.82 / Default 7 comparison covers the native Nudge unit menu and Position Nudge with `minutes:seconds` and `samples`.

The native unit menu contains `milliseconds`, `minutes:seconds`, `grid units`, `measures.beats`, `samples`, `frames`, `pixels`, `item lengths`, `item selections`, and `notes`. AAADAW previously offered `seconds` instead of the native `minutes:seconds` unit, so Nudge could not accept the time format used by REAPER. The dialog now exposes `milliseconds`, `minutes:seconds`, and `samples`, and parses Nudge amounts through the same signed project-time parser used by Set.

For an Audio item at 1.270 seconds, a 250 ms Nudge Right with `minutes:seconds` moves the item to 1.520 seconds with Snap off, and to 2.000 seconds with Snap on. A one-sample Nudge at 44.1 kHz moves it to 1.270022676 seconds; enabling Snap leaves that one-sample result unchanged. All four native measurements preserve the 0.500-second item length and 0.200-second source offset, retain selection, and report zero project state-change delta. AAADAW now maps `minutes:seconds` to project samples and rounds Position Nudge destinations to the nearest whole second when Snap is enabled. The regression checks right and left rounding, Snap on/off, one-sample granularity, preserved item geometry and selection, and one-step Undo/Redo. REAPER's other Nudge units—grid units, measures.beats, frames, pixels, item lengths, item selections, and notes—remain unimplemented and are still part of the open parity gap.
