# Item Nudge units and Snap

This REAPER 7.82 / Default 7 comparison covers the native Nudge unit menu and Position Nudge with `minutes:seconds`, `grid units`, `measures.beats`, `samples`, and `frames`.

The native unit menu contains `milliseconds`, `minutes:seconds`, `grid units`, `measures.beats`, `samples`, `frames`, `pixels`, `item lengths`, `item selections`, and `notes`. AAADAW previously offered `seconds` instead of the native `minutes:seconds` unit, so Nudge could not accept the time format used by REAPER. Position Nudge now exposes `milliseconds`, `minutes:seconds`, `grid units`, `measures.beats`, `samples`, and `frames` in native order. Grid-unit Nudge derives its PPQ interval from the Arrangement Snap Grid and converts the target through the project Tempo Map; Snap to grid rounds the first selected item's target to that musical grid before moving the selection by one shared project-time delta. Measures.Beats Position Nudge converts measure/beat counts using the time signature active at the first selected item and maps the destination through the Tempo Map; Snap to bar rounds that destination to the nearest measure boundary before applying one shared delta. Frame Nudge converts frame amounts using the project's actual frame-rate ratio and, with Snap enabled, rounds the first selected item's destination to the nearest frame boundary.

For an Audio item at 1.270 seconds, a 250 ms Nudge Right with `minutes:seconds` moves the item to 1.520 seconds with Snap off, and to 2.000 seconds with Snap on. A one-sample Nudge at 44.1 kHz moves it to 1.270022676 seconds; enabling Snap leaves that one-sample result unchanged. All four native measurements preserve the 0.500-second item length and 0.200-second source offset, retain selection, and report zero project state-change delta. The values and operation fixture are in [the native TSV](fixtures/item-nudge-unit-snap-native.tsv); the actual dialog and arrange captures are [the unit menu](fixtures/item-nudge-unit-menu-native.png), [time Snap on](fixtures/item-nudge-time-snap-native-after.png), [time Snap off](fixtures/item-nudge-time-no-snap-native-after.png), and [sample Snap on](fixtures/item-nudge-samples-snap-native-after.png).

AAADAW maps `minutes:seconds` to project samples and rounds Position Nudge destinations to the nearest whole second when Snap is enabled.

## Grid units

In the native 44.1 kHz project at 120 BPM and 4/4, one quarter-note `grid unit` moves the item at 1.270s to 1.770s with Snap off, to 2.000s with Snap on, and to 1.000s for a left Nudge with Snap on. These native operations preserve item length, source offset, and selection, and create a `Nudge items` undo entry. The [grid/measure probe TSV](fixtures/item-nudge-grid-measures-native.tsv) records the values; screenshots show the [grid controls](fixtures/item-nudge-grid-units-native-configured.png), [Snap off result](fixtures/item-nudge-grid-units-native-no-snap-after.png), [Snap on result](fixtures/item-nudge-grid-units-native-snap-after.png), and [left Snap result](fixtures/item-nudge-grid-units-native-snap-left-after.png).

AAADAW regressions check grid-unit right and left movement, Snap on/off, preserved item geometry and selection, and one-step Undo/Redo.

The native probe measured `measures.beats`: `1.0` moves one 4/4 bar (2 seconds at 120 BPM), `0.1` moves one beat, and Snap to bar rounds a 1.270s start plus one bar to 4.000s. Those measurements are captured in the [native TSV](fixtures/item-nudge-grid-measures-native.tsv) and [dialog](fixtures/item-nudge-measures-beats-native-configured.png), [Snap off](fixtures/item-nudge-measures-beats-native-no-snap-after.png), and [Snap on](fixtures/item-nudge-measures-beats-native-snap-after.png) screenshots. AAADAW now matches these Position Nudge values; its regression also checks static 3/4 measure length, item geometry, selection, and one-step Undo/Redo. Variable-meter changes crossed during a nudge, and Measures.Beats with other Nudge targets, still need native comparison.

## Frames

The native project uses 44.1 kHz and 30 fps non-drop. From 1.270 seconds, a one-frame Nudge Right lands at 1.303333333 with Snap off and 1.300000000 with Snap on. A one-frame snapped Nudge Left lands at 1.233333333. A half-frame Nudge Right lands at 1.286666667 without Snap and rounds to 1.300000000 with Snap. Every measured result retains the 0.500-second length, 0.200-second source offset, and selection; native Undo labels the operation `Nudge items`. The [native TSV](fixtures/item-nudge-frames-native.tsv) and screenshots capture the [unit menu](fixtures/item-nudge-frames-unit-menu-native.png), [one-frame setup/result](fixtures/item-nudge-frames-native-configured.png) / [Snap off](fixtures/item-nudge-frames-native-no-snap-after.png) / [Snap on](fixtures/item-nudge-frames-native-snap-after.png), [left Snap result](fixtures/item-nudge-frames-native-snap-left-after.png), and [half-frame setup/results](fixtures/item-nudge-frames-native-half-configured.png) / [Snap off](fixtures/item-nudge-frames-native-half-no-snap-after.png) / [Snap on](fixtures/item-nudge-frames-native-half-snap-after.png).

AAADAW now exposes `frames` after `samples` in the Unit menu, uses the exact project frame-rate ratio for Nudge conversion (including fractional frame amounts), and snaps to the nearest frame boundary. Regression checks match the native 30 fps cases, preserve geometry and selection, exercise Undo/Redo, and cover a 29.97 fps frame boundary whose sample position is fractional before rounding. The actual [selected Frames dialog](fixtures/aaadaw-frames-live-selected.png) shows the default value `1` and `Snap to unit`; the [scrolled Unit menu](fixtures/aaadaw-frames-live-unit-menu-scrolled.png) shows `samples` followed by `frames`.

Native Frames operation rows report a +1 state-change delta and `Nudge items` undo label, while the earlier minutes:seconds/sample probe reports zero; native Undo-counter parity therefore remains unsettled. Native behavior is measured here only for Position Nudge at the default 30 fps rate. Other Nudge targets, fractional project frame rates in REAPER, and the remaining `pixels`, `item lengths`, `item selections`, and `notes` units still need native comparison.

The existing minutes:seconds/sample TSV reports zero project state-change delta, while the new grid/measure run reports a +1 delta and the undo label `Nudge items`; that discrepancy is not yet reconciled and needs a controlled repeat before treating native Undo-counter parity as settled.
