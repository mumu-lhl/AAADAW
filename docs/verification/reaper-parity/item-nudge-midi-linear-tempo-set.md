# MIDI Set → Contents during a linear tempo ramp

Linux REAPER `7.82/linux-x86_64` with `Default_7.0.ReaperThemeZip` was opened in a fresh unsaved project. The probe enabled a 120-to-60 BPM linear ramp from project start to measure 3 (5.333333 seconds), then created a selected loop-source MIDI item from 3.900 to 8.900 seconds with two notes.

In the real 528×121 `Nudge/Set Items` dialog, Mode was `Set`, Target was `contents`, the absolute target was 4.150 seconds, and Snap was off. Apply kept the item at 3.900 seconds with its five-second length, loop flag, selection, and note PPQ unchanged. REAPER reported `D_STARTOFFS=3.041994609` seconds, source phase 4,537.985 PPQ, and loop endpoint 9,522.885 PPQ. The state-change count advanced once, from 2 to 3. The [native TSV](fixtures/item-nudge-midi-linear-tempo-set-native.tsv) records these values; the [before](fixtures/item-nudge-midi-linear-tempo-set-native-before.png) and [after](fixtures/item-nudge-midi-linear-tempo-set-native-after.png) files are actual REAPER desktop captures.

The App regression applies the same absolute target and preserves item bounds, loop length, notes, selection, and one-step Undo/Redo. AAADAW's Tempo Map now matches REAPER's time-linear ramp: the project stores phase 4,538 PPQ in a 4,985-tick loop, against REAPER's 4,537.985 phase and 4,984.900 PPQ endpoint. The converted source offset is 3.041977506 seconds, within 17 microseconds of REAPER's 3.041994609 seconds. The remaining difference comes from integer PPQ storage; exact sub-tick source phase and complete `ITEM-NUDGE-SET-001` parity remain open.

The [ReaScript probe](../../../scripts/reaper_parity/probe-item-nudge-midi-linear-tempo-set.lua) builds the tempo map and MIDI item and opens the native dialog. Set Mode/Target/value in that dialog, apply once, then write `snapshot` and `done` to its command file in `AAADAW_REAPER_PROBE_DIR` to record the resulting state. The stepped-tempo Set case is recorded separately in [MIDI Set → Contents across a stepped tempo change](item-nudge-midi-variable-tempo-set.md).
