# MIDI Event Filter: Clear Filter

Reference: Linux REAPER 7.82, Default 7 theme. `Clear filter` resets the Filter Events dialog and MIDI Editor channel filter while leaving the dialog open.

The native probe began with Note selected as the event type, only channel 5 checked, Show-only enabled, and draw channel 5. Clear filter disabled Show-only, selected `<all events>` and all channels, changed the editor channel to All channels, and reset the draw channel to Channel 1. A follow-up turned Invert and Solo on before clearing: Invert turned off, while Solo remained on. The native readback stores the Solo option separately from the cleared filter state. The four-note project and all four selected Notes remained intact. The before/after screenshots and saved RPP readbacks are in the [fixture manifest](fixtures/midi-event-filter-clear-native.tsv). Parameter, Value, Position, Repeat, and Length criteria were not enabled during the probe, so their individual reset behavior is still unmeasured.

AAADAW now resets the corresponding modeled state: visibility filtering, channel mask, event type, inversion, editor channel selection, and draw channel. Filter visibility and criteria changes preserve selected events even when their rows are hidden. Clear leaves the filter dialog open, restores visibility, preserves all event selections, and does not create project or Undo history changes. The app regressions check that changing filter visibility preserves hidden selections, then verify the reset values, full row visibility, mixed selection preservation, and unchanged project snapshot. Current-build Xvfb before/after screenshots and the binary SHA-256/Build ID are recorded in the [AAADAW fixture manifest](fixtures/midi-event-filter-clear-aaadaw.tsv).

Clear filter resets the AAADAW filter state it currently models, including the Note Position and Length ranges and the Control/Value criteria for CC events. The native probe leaves Control/Value reset behavior unmeasured and confirms Clear leaves Solo unchanged. Repeat and Solo remain unimplemented; selected-Note range derivation is documented in the [Set filter from selection record](midi-event-filter-from-selection.md). The [Event List parity record](midi-event-list.md) keeps those items open.
