# MIDI Editor Event List

Reference: Linux REAPER 7.82, Default 7 theme. MIDI Editor action 40056 switches to Event List and is bound to Alt+3; Alt+1 returns to Piano Roll. The native capture shows the event table columns `Index`, `Position`, `Length`, `Channel`, `Type`, `Parameter`, `Value`, `Off Value`, and `REAPER Data`. It also displays a synthetic terminal `(end) All Notes Off` row, including when the MIDI item has no stored events. The repeatable probes record both the four-note item and the empty-item case; readbacks, native screenshots, and AAADAW real-window captures are listed in the [fixture manifest](fixtures/midi-event-list-ui.tsv).

AAADAW now exposes Piano Roll and Event List modes in the MIDI Editor and Action List. Event List presents modeled Notes, Control Change, Pitch Bend, Program Change, Poly Aftertouch, and Channel Pressure entries in project BBT positions, with note lengths, one-based channels, parameter/value fields, and off values. It appends `(end) All Notes Off` at the item length as a synthetic cursor row, not a stored or exported MIDI event. An empty item therefore shows one row at its end; the row can be selected and navigated to, and Delete/Backspace leaves the project unchanged. Delete on a modeled row removes that event. Real-window captures verify the empty row, the populated row, no-op deletion of the terminal row, and deletion of a real note. Note rows display persistent MIDI Note Off velocity in `Off Value`; the native and AAADAW fixture uses Note On 91 / Note Off 37 and verifies the displayed 37 in Event List and Event Properties. Apply changes it to 42, and Undo/Redo restore 37/42. See the [note-off velocity fixture manifest](fixtures/midi-note-off-velocity-ui.tsv). REAPER 7.82 displays a Program Change's raw zero-based program number in the Value column: the native probe inserts program 41 and both its Event List and Bank/Program Select dialog show 41. AAADAW displays the same value and labels the row `PC`. Poly Aftertouch uses the native pitch name (for example `C4`) in Parameter; Channel Pressure has no parameter. Native REAPER and real-window AAADAW captures and readbacks for both pressure event types are in the [aftertouch fixture manifest](fixtures/midi-aftertouch-ui.tsv). Existing MIDI channel and event-type filters apply to modeled rows; filter behavior for the synthetic row has not yet been verified against REAPER. Clicking a row selects it; Ctrl/Cmd-click toggles it. Delete removes selected modeled events as one undoable transaction. The in-memory mode does not alter MIDI project data.

For one or more selected rows of the same modeled type, `Edit event…` and action 40004 (`Ctrl+F2`) open Event Properties. Notes expose absolute Position, Length, Channel, Pitch, Note On Velocity, and Note Off velocity; CC events expose Position, Channel, Controller, and Value; Pitch Bend exposes Position, Channel, and raw 14-bit Value; Program Change exposes Position, MIDI channel, and its zero-based Program number; Poly Aftertouch exposes Position, Channel, Note, and Value; Channel Pressure exposes Position, Channel, and Value. REAPER opens a dedicated `Bank/Program Select` dialog for a Program Change. AAADAW uses a matching title but does not yet expose Bank MSB/LSB or patch-file selectors. Apply leaves the dialog open after one undoable update; OK commits and closes it; Cancel and Escape discard the current uncommitted fields. The separate [Event Properties verification](midi-event-properties.md) records the measured native dialogs and AAADAW windows.

Arrow Up/Down now follows the measured row-selection behavior: the first unmodified arrow collapses a multi-selection at its active row, and the next arrow moves to the adjacent visible event. Ctrl+Arrow Up/Down moves the independent Event List cursor while retaining the selected rows. Shift+Arrow Up/Down extends or contracts the selection from its anchor across every visible event row, including mixed Note, CC, and Pitch Bend rows. The [native navigation trace](fixtures/midi-event-list-navigation-native.tsv) records the selection bits after each step; native and current-build AAADAW screenshots are in the [fixture manifest](fixtures/midi-event-list-ui.tsv). In the native Event List, double-clicking a value opens the complete Event Properties dialog rather than editing that cell inline, so direct per-cell editing is not a parity gap.

This is a partial implementation, not full Event List parity. Ctrl+F2 on REAPER's synthetic terminal row opens a blank Event Properties dialog; AAADAW does not yet provide that blank dialog. AAADAW also lacks Program Change bank/patch-file behavior and native Parameter formatting, SysEx or MIDI text/meta events, and REAPER Data. Mixed-type event properties, Shift+click range selection, horizontal field navigation, Home/End behavior, sorting/column sizing, and context menus remain open. BBT is currently derived from the project meter and PPQ without REAPER source-offset/loop-occurrence display semantics. Mode persistence between editor closes or application restarts has not been established. These differences keep `MIDI-EVENT-LIST-001`, UI-019, and P7 `in_progress`.

The initial layout screenshots use a two-note AAADAW project and the four-note native probe. The new navigation captures use that native probe and an AAADAW project with CC, Pitch Bend, and two Notes. The terminal-row captures use an empty item and a four-note item, matching REAPER's end position at `3.1.00`; they are real-window behavior evidence, not a pixel-diff comparison. Automated App tests cover mode shortcuts/commands, empty and populated item terminal rows, mixed event ordering and channel filtering, BBT formatting, event selection and navigation, Delete routing/no-op behavior, one-step event deletion, Undo and Redo.
