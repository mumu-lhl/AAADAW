# MIDI Editor Event List

Reference: Linux REAPER 7.82, Default 7 theme. MIDI Editor action 40056 switches to Event List and is bound to Alt+3; Alt+1 returns to Piano Roll. The native capture shows the event table columns `Index`, `Position`, `Length`, `Channel`, `Type`, `Parameter`, `Value`, `Off Value`, and `REAPER Data`. It also displays the terminal `(end) All Notes Off` row. The repeatable probe creates four notes with staggered channel, pitch, selection, and velocity values, opens the MIDI editor, and records the source events. Exact ReaScript readbacks, the native screenshot, and the AAADAW screenshot are listed in the [fixture manifest](fixtures/midi-event-list-ui.tsv).

AAADAW now exposes Piano Roll and Event List modes in the MIDI Editor and Action List. Event List currently presents modeled Notes, Control Change, and Pitch Bend entries in project BBT positions, with note lengths, one-based channels, parameter/value fields, and off values. Existing MIDI channel and event-type filters apply. Clicking a row selects it; Ctrl/Cmd-click toggles it. Delete removes the selected modeled events as one undoable transaction. The in-memory mode does not alter MIDI project data, and the AAADAW fixture is a real desktop-window capture from the current build.

For one or more selected rows of the same modeled type, `Edit event…` and action 40004 (`Ctrl+F2`) open Event Properties. Notes expose absolute Position, Length, Channel, Pitch, and Velocity; CC events expose Position, Channel, Controller, and Value; Pitch Bend exposes Position, Channel, and raw 14-bit Value. Apply leaves the dialog open after one undoable update; OK commits and closes it; Cancel and Escape discard the current uncommitted fields. The separate [Event Properties verification](midi-event-properties.md) records the measured native dialogs and AAADAW windows.

Arrow Up/Down now follows the measured row-selection behavior: the first unmodified arrow collapses a multi-selection at its active row, and the next arrow moves to the adjacent visible event. Ctrl+Arrow Up/Down moves the independent Event List cursor while retaining the selected rows. The [native navigation trace](fixtures/midi-event-list-navigation-native.tsv) records the selection bits after each step; the native and current-build AAADAW screenshots are in the [fixture manifest](fixtures/midi-event-list-ui.tsv). In the native Event List, double-clicking a value opens the complete Event Properties dialog rather than editing that cell inline, so direct per-cell editing is not a parity gap.

This is a partial implementation, not full Event List parity. AAADAW does not yet model the native terminal all-notes-off row, Program/Bank, Poly Aftertouch, Channel Pressure, SysEx or MIDI text/meta events, or REAPER Data. Mixed-type event properties, persistent note-off velocity, Shift+Arrow range selection, horizontal field navigation, Home/End behavior, sorting/column sizing, and context menus remain open. BBT is currently derived from the project meter and PPQ without REAPER source-offset/loop-occurrence display semantics. Mode persistence between editor closes or application restarts has not been established. These differences keep `MIDI-EVENT-LIST-001`, UI-019, and P7 `in_progress`.

The initial layout screenshots use a two-note AAADAW project and the four-note native probe. The new navigation captures use that native probe and an AAADAW project with CC, Pitch Bend, and two Notes. They are real-window behavior evidence, not a pixel-diff comparison. Automated App tests cover mode shortcuts/commands, mixed event ordering and channel filtering, BBT formatting, event selection and navigation, one-step delete, Undo and Redo.
