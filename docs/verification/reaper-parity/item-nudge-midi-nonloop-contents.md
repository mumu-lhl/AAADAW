# Non-loop MIDI Contents Nudge on REAPER 7.82

Linux REAPER `7.82/linux-x86_64` with the `Default_7.0.ReaperThemeZip` theme was run in a fresh, unsaved project. The probe created a selected five-second MIDI item at 2 seconds, disabled `Loop source`, inserted two notes, and opened Main action 41226 (`Item edit: Nudge/Set...`). The real dialog was set to Nudge, Target `contents`, 250 milliseconds, Snap off; the captured [dialog](fixtures/item-nudge-midi-nonloop-native-left-zero.png) shows the configured target and amount.

The source offset boundary has two native representations. Starting at 100 ms, a left Nudge changes `D_STARTOFFS` to 350 ms and leaves the notes and ten-quarter-note source unchanged. A right Nudge clamps the offset to zero, moves the notes forward by 288 PPQ, and extends the source to 10.3 quarter notes. Starting at zero, a left Nudge keeps the offset at zero, moves the notes backward by 480 PPQ, and shortens the source to 9.5 quarter notes. Applying left after the right case moves the notes back to the same audible item-relative times as the initial state, with the source rebased at zero. The item remains at 2–7 seconds and selected in every state. Exact source lengths, phases, event positions, and native state-change counters are in the [fixture TSV](fixtures/item-nudge-midi-nonloop-native.tsv); the reproducible [ReaScript probe](../../../scripts/reaper_parity/probe-item-nudge-midi-nonloop.lua) accepts `AAADAW_REAPER_PROBE_SOURCE_OFFSET_SECONDS=0` to probe a zero offset. Direct Nudge state-change counters varied across the chained actions, so this fixture does not make an Undo-history claim.

AAADAW now supports non-loop MIDI Contents Nudge without making the stored source offset signed. When a right Nudge passes the source start, it clamps the offset to zero and rebases notes, controllers, and pitch bends forward while extending the source. At zero offset, a left Nudge rebases those events backward and shortens the source. Away from zero, a left Nudge advances the positive source offset while leaving events untouched. These edits are one `SetMidiItemContents` project transaction; the signed event shift preserves note IDs and participates in Undo/Redo. The regressions match REAPER's 100 ms left/right note and source-length values and zero-offset left values, and additionally verify controller and pitch-bend shifts, selection, item bounds, and Undo/Redo.
